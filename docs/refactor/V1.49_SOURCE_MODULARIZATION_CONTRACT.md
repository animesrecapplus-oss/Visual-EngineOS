# V1.49 — Source modularization contract

## Scope

Audit the V1.48 source tree and extract exactly one real responsibility from exactly one module.
The line-count threshold is an inventory signal, never the extraction criterion.

## Required sequence

1. audit dependency graph;
2. inventory responsibilities and module sizes;
3. trace real consumers;
4. inspect duplicate candidates and reject false positives manually;
5. choose one module;
6. choose one responsibility;
7. extract it with one owner;
8. test public/legacy API identity, adversarial invariants and import cycles;
9. run the complete regression matrix;
10. benchmark the affected path against V1.48;
11. validate a real render when the seam can affect geometry/output;
12. update bounded documentation;
13. purge superseded generated evidence while keeping the current artifact area;
14. produce the certified ZIP outside the project tree.

## Selected seam

Source: `runtime/geometry_transform.py`.

Responsibility extracted: **renderer-independent transformation of a `GeometryContract` between 2D
coordinate frames**. This includes bounds, paths, supported geometric primitives, anchors, z offset,
and affine ellipse-axis mapping.

Context resolution remains in `runtime/geometry_transform.py`: component hierarchy, placement,
camera and world/scene/camera matrices are not moved.

## Compatibility

`runtime.transform_geometry_contract` and `runtime.geometry_transform.transform_geometry_contract`
remain valid public/legacy entry points and must resolve to the single implementation in
`runtime.geometry_contract_transform`.

## Non-goals

No renderer redesign, no visibility semantic change, no COLOR change, no cache change, no second
module extraction and no new geometry feature.
