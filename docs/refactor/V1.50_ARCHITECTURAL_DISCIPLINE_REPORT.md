# V1.50 — Architectural discipline report

## Scope

V1.50 establishes the new engineering discipline before continuing source modularization and applies it to one pilot only: `CMP-EYE-PUPIL`.
The repository was not globally restructured.

## Protocols created

`docs/governance/protocols/` now contains the architectural immune system, component truth, impact analysis, hostile review,
visual execution, naming/cleanup, traceability and ordered protocol-gate rules.

`docs/governance/architecture/COMPONENT_TRUTH_ARCHITECTURE.md` defines the semantic code/docs/test mapping and incremental adoption policy.

`tools/preflight_architectural_gate.py` provides a read-only pre-change cleanliness gate. `tools/validate_component_truth.py` provides the pilot dossier gate. `LINE_BUDGET_DEBT.md` makes the 68 pre-existing oversized modules explicit and prevents silent exception drift.

## Pilot dossier

`docs/components/eyes/pupil/` contains identity, truth, roadmap, contracts, dependencies/consumers, invariants/assumptions,
adversarial matrix, test status, decisions, errors, impact map, evidence and a machine-readable manifest.

Pilot tests live under `tests/components/face/eyes/pupil/`.

## Concrete architectural defect found and corrected

The pilot exposed `LashShadowSpec` inside `pupil/effects.py` although its semantic owner and consumers are the lash system.
It was moved to `lashes/effects.py`. `appearance/spec.py`, `eyes/definitions.py`, `eyes/effects/__init__.py` and `lashes/__init__.py` were rewired.
The historical `geometry.LashShadowSpec` remains the same Python object as the new owner.

This is deliberately recorded as a governance-pilot correction, not counted as a broad modularization campaign.

## Maintainability

`pupil/spec.py`, `pupil/effects.py` and `pupil/__init__.py` are all ≤150 lines and have explicit ownership/contract/invariant comments on every non-blank code line.
The new lash effect owner is also fully commented and ≤150 lines.
