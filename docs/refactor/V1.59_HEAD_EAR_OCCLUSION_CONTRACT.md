# V1.59 Head/Ear production visibility — Contract

## Scope

One bounded production relation: the existing HumanFace head surface occludes the existing Ear targets where
real camera-space overlap is measured.

## Owners

- `CMP-RUNTIME-PRODUCTION-PAIR-OCCLUSION` — `src/visual_engine/runtime/production_pair_occlusion.py:17-107`.
- `CMP-PROD-HEAD-EAR-OCCLUSION` — `src/visual_engine/runtime/production_head_ear_occlusion.py:16-78`.
- `CMP-RUNTIME-VISIBILITY-DEPTH-RELATION` — `src/visual_engine/runtime/visibility.py:254-259`.

## Guarantees

1. Ear is the visibility target; HumanFace is the head-surface owner/occluder.
2. Equal authored depth is preserved as `COPLANAR`; the relation explicitly enables coplanar occlusion.
3. Resolved Head visibility/opacity/transmission are forwarded without COLOR transformation.
4. Head/Ear does not claim causal attribution because no downstream attribution consumer exists.
5. Existing Hair/Ear attribution and public API remain intact.
6. No database schema/migration or new cache owner is introduced.

## Non-goals

No renderer clipping/masking rewrite, negative depth semantics, ear morphology, accessories, Hair morphology,
COLOR change or causal consequence rule is introduced.
