# V1.56 — Ear production contract

## Scope

One production family: `Ear` plus its explicit HumanFace composite adapter and the minimal generic SVG role needed to paint it.

## Ownership

- `CMP-FACE-EAR` → `src/visual_engine/components/face/ear.py`.
- `CMP-FACE-EAR-COMPOSITE` → `src/visual_engine/components/face/ear_composite.py`.
- `CMP-RENDER-GEOMETRY-SVG-EAR-ROLE` → `src/visual_engine/render/geometry_svg.py`.

## Consumer proof

The production consumer is `ProductionRenderSession.render_face`, whose default generator is `face.human_with_eyes_nose_mouth_ears`. The registry and generic cache/renderer are real downstream consumers.

## Compatibility

`face.human_with_eyes_nose_mouth` remains explicitly callable. No historical registry mutation was introduced.

## COLOR / persistence

No COLOR semantic consumer was introduced. No database migration or schema change is introduced; generic persistence is reused.
