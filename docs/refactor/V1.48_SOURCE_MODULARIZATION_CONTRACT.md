# V1.48 — Source-code modularization contract

## Objective

Reduce responsibility mixing in runtime Python without splitting files mechanically by line count.
The 150-line discipline remains mandatory for documentation; source extraction is driven by ownership,
cohesion, dependency direction and public contracts.

## Audit gate

Before an extraction:

1. inventory every `src/**/*.py` module above 150 lines;
2. build the direct import graph;
3. detect import cycles and compare them with the pre-change graph;
4. detect exact duplicate function bodies;
5. inspect high-similarity candidates semantically;
6. trace real consumers and tests;
7. select exactly one module and one autonomous responsibility.

## V1.48 selected seam

`visual_engine.runtime.visibility` mixed two responsibilities:

- planar-region materialization (`GeometryContract`/path/primitive ↔ Shapely region);
- boolean visibility, depth filtering, optical visibility and event emission.

The first responsibility is extracted to:

`src/visual_engine/runtime/region_geometry.py`

The new module owns `BooleanPolygon`, `RegionGeometry`, path/primitive conversion, polygon cleanup and
GEOS-region → contract conversion. It has exactly 150 lines at the certified source freeze.

## Compatibility

The runtime package continues exporting the same public names. The old `visibility` module also keeps
compatibility imports for `path_to_region`, `primitive_to_region`, `geometry_to_region` and
`region_to_contract`. Internal consumers now import the new owner directly where appropriate.

## Non-goals

- no behavioral change to visibility;
- no new rendering feature;
- no new COLOR behavior;
- no cache policy change;
- no broad multi-module extraction;
- no automatic splitting of every module above 150 lines.

## Acceptance

The brick is accepted only if focused visibility tests, production visibility tests, full regression,
compile checks, import-graph audit, public-API identity checks and benchmark comparison pass. The visual
renderer is not re-certified because no rendered geometry or renderer behavior changed.
