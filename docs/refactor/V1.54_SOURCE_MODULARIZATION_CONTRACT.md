# V1.54 — source modularization contract

## Scope

Apply the architectural immune-system protocol to exactly one responsibility selected from a fresh V1.53 re-audit.

## Selected seam

- Audited module: `runtime.domain_resolution`.
- Responsibility: canonical construction and normalization of `DomainResolutionInput`.
- Canonical owner: `runtime.domain_input_factory`.
- Compatibility facade: `runtime.domain_resolution`.

## Included

`build_domain_resolution_input`, including domain admission, dependency normalization, typed-role dependency identity and state canonicalization.

## Excluded

`DomainResolutionInput` storage contract, `unresolved_domain_result`, result validation, domain algorithms, persistence, cache/fingerprint ownership and rendering.

## Mandatory guarantees

- exactly one factory implementation;
- BASE/COLOR/MATERIAL consumers use the canonical owner;
- historical/public facade identity remains compatible;
- canonical owner does not import the facade;
- no new dependency cycle;
- no exact duplicate implementation;
- valid input/digest semantics remain unchanged;
- no persistence/database change;
- no COLOR semantic change;
- new owner remains ≤150 lines.

## Visual boundary

The factory performs no geometry, visibility, camera or renderer work. Visual QA is `NOT_APPLICABLE`; no synthetic visual evidence is permitted.

## Retention

Only `artifacts/current/v1.54/` is retained as generated current evidence. Historical documentation remains provenance.
