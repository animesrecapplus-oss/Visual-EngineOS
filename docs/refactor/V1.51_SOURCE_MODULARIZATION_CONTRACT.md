# V1.51 — source modularization contract

## Scope

V1.51 applies the V1.50 architectural-immune-system protocol to one responsibility-driven extraction.

## Selected seam

- Module: `src/visual_engine/runtime/domain_resolution.py`.
- Responsibility extracted: validation of `DomainResolutionResult` against input identity, domain contract and provenance.
- Canonical owner: `src/visual_engine/runtime/domain_result_validation.py`.
- Compatibility owner: legacy `domain_resolution.validate_domain_resolution_result` import facade only.

## Selection proof

The responsibility has three real production consumers: BASE, COLOR and MATERIAL domain resolvers. It has an independent contract boundary and does not require persistence, rendering or geometry semantics.

## Mandatory guarantees

- one implementation owner;
- legacy/public import identity preserved;
- no new dependency cycle;
- exact duplicate audit remains clean;
- existing validation behaviour remains unchanged;
- persistence/database boundary remains unchanged;
- COLOR semantic implementation remains frozen;
- new source and durable documentation stay ≤150 lines;
- new owner has explicit comment coverage.

## Hostile boundary

The validator must reject target/domain/resolver mismatch, stale input digest, undeclared fields, missing required output, role lineage drift, contribution/dependency substitution, dependency digest drift and non-finite field values through the canonical field contract.

## Visual boundary

The seam contains no geometry or renderer operation. Visual QA is therefore not an independent V1.51 artifact; production integration and full regression remain mandatory.

## Release boundary

Before certification, purge superseded generated evidence but keep `artifacts/` and retain only `artifacts/current/v1.51/`. The certified ZIP is outside the project tree.
