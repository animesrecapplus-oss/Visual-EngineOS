# V1.53 — source modularization contract

## Scope

V1.53 applies the architectural-immune-system protocol to one responsibility selected only after re-audit,
consumer tracing and impact analysis.

## Selected seam

- Audited module: `src/visual_engine/runtime/domain_resolution.py`.
- Responsibility: immutable domain-input contract.
- Canonical owner: `src/visual_engine/runtime/domain_input_contract.py`.
- Compatibility owner: `domain_resolution` factory/re-export surface.

## Included contract

`DomainDependency` and `DomainResolutionInput`, including constructor invariants and deterministic `input_digest`.

## Excluded

`build_domain_resolution_input`, `unresolved_domain_result`, result contract, result validation, domain algorithms,
persistence, cache ownership, fingerprints and rendering.

## Hostile correction

V1.53 adds explicit runtime type guards for the input domain, target/resolver identity, contributions and dependencies,
plus canonical state/dependency ordering. Valid inputs and digest semantics remain unchanged.

## Mandatory guarantees

- one canonical implementation owner;
- historical/public imports remain identity-compatible;
- canonical owner does not import `domain_resolution`;
- no new dependency cycle;
- exact duplicate audit remains clean;
- input digest remains deterministic;
- persistence/database and cache/fingerprint boundaries remain unchanged;
- COLOR semantics remain frozen;
- new source stays at or below 150 lines.

## Visual boundary

The selected responsibility contains no geometry, visibility, camera or renderer operation. Visual QA is
`NOT_APPLICABLE`; no synthetic image evidence is permitted.

## Release boundary

Retain only `artifacts/current/v1.53/`. The certified ZIP remains external to the project tree.
