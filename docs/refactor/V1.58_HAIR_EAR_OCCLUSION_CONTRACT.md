# V1.58 Hair/Ear Occlusion — Contract

## Scope

Implement one bounded production interaction: certified Hair as an occluder of the two existing HumanFace Ear targets.

## Owners

- `CMP-FACE-HAIR-DEPTH` — `src/visual_engine/components/face/hair.py:46-48`.
- `CMP-PROD-HAIR-EAR-OCCLUSION` — `src/visual_engine/runtime/production_hair_ear_occlusion.py:1-91`.

## Guarantees

1. Hair depth is authored at `1`; Ear remains `0`.
2. The adapter uses exactly one semantic area region for each bounded owner.
3. Generic visibility and attribution remain the authoritative spatial algorithms.
4. Resolved Hair effective visibility becomes occluder opacity.
5. Hair material transmission is forwarded without COLOR transformation.
6. Existing V1.47 head overlap and V1.55/V1.56/V1.57 production generators remain available.
7. No database schema or migration is introduced.
8. No new cache owner or cache identity is introduced.
9. Real visual evidence is required and stored under `artifacts/current/v1.58/`.

## Hostile contract

Reject wrong owner kinds, identical ids, non-finite depths, opacity/transmission outside `[0,1]`, and ambiguous/no semantic area regions.

## Non-goals

No strand-level hair, volumetric hair, accessories, new boolean kernel, COLOR consumer, or generic renderer rewrite.
