# Decisions — V1.85

## DEC-V185-001 — continue without Git gate

The project is explicitly not a Git repository. Git cleanliness is therefore not treated as a project certification
prerequisite. Certification uses source identity, tests, dependency graph, persistence identity, deterministic visual
evidence, documentation and artifact integrity instead.

## DEC-V185-002 — select Lash horizontally

The fresh audit found a real executable Lash owner with direct renderer consumers and reproducible local validation
defects. Iris/Pupil were deferred because their corresponding hardening bricks already exist; planned Hair atoms were
not promoted.

## DEC-V185-003 — keep the brick local

Only `lashes/spec.py` changes at runtime. Geometry, renderer algorithms, cache identity, COLOR and database layers
remain outside scope. This minimizes risk while closing a verified input boundary.

## DEC-V185-004 — no maximum count invented

The renderer consumes `count`, but no verified resource ceiling exists in the current contract. V1.85 therefore
rejects fractional/bool counts without inventing a maximum integer ceiling.
