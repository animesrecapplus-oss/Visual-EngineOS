  defects are verified; recent hardened siblings remain deferred.
- `DEC-HIGHLIGHT-002`: keep validation local; do not change shared `_finite`.
- `DEC-HIGHLIGHT-003`: close the existing four-value shape vocabulary because the renderer has four intended branches and
  previously accepted unknown values.
- `DEC-HIGHLIGHT-004`: reject non-bool/non-Real/non-finite numeric values without coercion.
- `DEC-HIGHLIGHT-005`: preserve placement authority, cache identity, COLOR and persistence boundaries.
- `DEC-HIGHLIGHT-006`: local validation is preferred over shared `_finite` modification to limit blast radius.
- `DEC-HIGHLIGHT-007`: tuple membership is used so unhashable malformed shape values fail with the domain error.
- `DEC-HIGHLIGHT-008`: retain the renderer fallback implementation; prevent invalid values from reaching it instead.
