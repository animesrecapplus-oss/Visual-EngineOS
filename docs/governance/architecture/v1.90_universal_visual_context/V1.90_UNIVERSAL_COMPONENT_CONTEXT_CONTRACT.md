# V1.90 — Universal Visual Component Context Contract

**Status:** ARCHITECTURAL CONTRACT / NOT YET RUNTIME IMPLEMENTED

Every render-affecting microcomponent dossier must account for the following axes. `NOT_APPLICABLE` is explicit; omission is not allowed.

1. Identity / stable component ID.
2. Semantic role.
3. Parent and direct semantic owner.
4. Children.
5. Siblings and cross-relations.
6. Local coordinate frame.
7. Structural/anatomical meaning when applicable.
8. Morphology / shape parameters.
9. Transform inheritance and non-inherited channels.
10. Bilateral/side semantics when applicable.
11. Relations and relation direction.
12. Hard, soft, statistical and aesthetic constraints.
13. Parent-feasibility constraints.
14. Visibility state.
15. Geometric coverage.
16. Occlusion relation.
17. Mask/clipping semantics.
18. Appearance domain contributions.
19. COLOR authority/provenance.
20. Material contract.
21. Optical response.
22. Lighting response.
23. Style profile.
24. Camera interaction.
25. Projection interaction.
26. Composition/framing interaction.
27. Procedural variation and seed lineage.
28. Temporal state/trajectory when applicable.
29. Persistence and provenance.
30. Geometry/resolution cache identity.
31. Direct and indirect consumers.
32. Production execution path.
33. Visual contract: normal/boundary/interaction cases.
34. Adversarial invariants.
35. Evidence and exact versioned line ranges.

## Mandatory context propagation

A parent-to-child propagation record must identify which context channels are inherited, transformed, constrained, or deliberately blocked. A child must not infer a parent contract from Python ancestry alone.

## Mandatory camera separation

`CAMERA`, `HEAD/ENTITY ORIENTATION`, `FACE ORIENTATION`, `EYE ORIENTATION` and `GAZE` are separate semantic channels. A prompt phrase such as `look left` must never silently become a camera rotation.

## Mandatory default provenance

Any unspecified value resolved by the engine must carry a source classification such as `prompt`, `component_default`, `parent_default`, `style_profile`, `system_default`, `inherited`, or `generated`. An undocumented fallback is not a certified aesthetic default.

## Mandatory vertical validation

For any change capable of changing rendered output:

`ATOM → PARENT → SIBLINGS/RELATIONS → ENTITY → SCENE → CAMERA → RENDER PLAN → FRAME → VISUAL INSPECTION → DIAGNOSIS → TEST → NEW EXECUTION`.

The vertical slice supplements, rather than replaces, unit, integration, deterministic, hostile and performance testing.
