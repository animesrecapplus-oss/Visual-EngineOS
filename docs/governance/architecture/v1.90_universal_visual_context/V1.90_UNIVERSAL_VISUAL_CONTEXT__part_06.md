# V1.90 — Universal Visual Context Audit — Part 06

## AUD-V190-033 — Procedural variation and seed

Deterministic seed handling is already part of the permanent grammar and the visual execution loop requires the deterministic seed to be recorded. The generic prompt compiler's seed resolution/provenance remains planned.

Evidence: `ENGINE_VISION__part_02.md:101-122`; `VISUAL_EXECUTION_LOOP.md:9-12`; `ROADMAP__part_02.md:39-60`.

**Classification:** deterministic seed infrastructure = `VERIFIED/PARTIAL`; prompt-derived seed policy = `PLANNED`.

## AUD-V190-034 — Temporal state

The vision explicitly reserves time, keyframes, easing, state transitions and procedural motion, but the roadmap marks animation as a future phase.

Evidence: `ENGINE_VISION__part_06.md:63-96`; `ROADMAP__part_02.md:63-72`.

**Classification:** animation architecture target = `PLANNED`; universal temporal component contract = `GAP`.

## AUD-V190-035 — Persistence / knowledge layer

PostgreSQL is already defined as cold-path source of truth for definitions, parameters, relations, constraints, profiles, appearance layers, states, styles, scene definitions, generation runs and render metadata. The renderer must not perform per-component/per-pixel DB access.

Evidence: `ENGINE_VISION__part_06.md:100-127`; `ARCHITECTURE_CONTRACT__part_02.md:A0 PostgreSQL lifecycle`.

**Classification:** persistence architecture = `VERIFIED`; prompt-to-persistence compiler = `PLANNED`.

## AUD-V190-036 — Cache and determinism

Geometry cache identity already excludes appearance-only changes and includes geometry inputs plus relevant hierarchy/relation dependencies. V1.89 specifically verified Gaze as a geometry cache input.

Evidence: `ENGINE_VISION__part_06.md:131-146`; V1.89 certification/status artifacts.

**Classification:** geometry cache boundary = `VERIFIED`.

## AUD-V190-037 — Production vertical slice gate

The project already has production face rendering, caller-owned render sessions, camera/placement inputs, resolution, geometry generation, appearance style resolution, SVG rendering and relation checks.

Evidence: `runtime/production_render_session.py:63-104`; `runtime/production_face_render.py:42-95`.

What is missing is a **mandatory component-development gate** that executes a canonical prompt-like semantic request through this production path for every render-affecting microcomponent change.

**Classification:** production render path = `VERIFIED`; universal per-brick vertical-slice gate = `GAP`.

## AUD-V190-038 — Universal component-context contract

The proposed universal axes are formalized as: identity; semantic role; parent/children/siblings; local frame; structure/anatomy; morphology; transform; relations; constraints; visibility; masking; occlusion; appearance; COLOR; material; optics; lighting response; camera interaction; composition; procedural variation; temporal state; persistence; cache identity; production consumers; visual contract; adversarial cases; evidence.

This is a **documentation/architecture contract proposal**, not an implemented mega-class.

## AUD-V190-039 — V1.90 decision boundary

V1.90 should **not** create a universal `VisualComponent` mega-class, a generic prompt compiler, a global camera manager, a second COLOR engine, a generic material shader, or a universal 3D renderer without real consumers and bounded contracts.

The evidence supports three immediate architectural priorities:

1. formalize the universal visual-context/vertical-slice contract;
2. correct the proven HumanFace bilateral-side propagation defect through its actual owner boundary;
3. define the owner/contract for generic aperture occlusion of ocular primitives before implementing it.

These are separate concerns and must not be fused into one opportunistic refactor.

## AUD-V190-040 — Proposed execution order

**V1.90:** architecture audit/formalization only; no runtime code change.

**Next implementation brick:** HumanFace→Eye bilateral identity propagation, after a fresh V1.89-based VERIFY/IMPACT pass.

**Following brick:** generic ocular aperture/depth/mask integration, only after owner proof and a production boundary visual test.

**Later:** prompt compiler/default resolver/camera-semantic compiler when a real production consumer and bounded IR contract exist.

## AUD-V190-041 — No certification overreach

This audit certifies only that the V1.89 baseline was inspected and the listed classifications are evidence-backed. It does **not** certify the current engine as visually correct, does not certify a prompt compiler, and does not certify a semantic default camera.
