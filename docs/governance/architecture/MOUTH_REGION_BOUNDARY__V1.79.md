# V1.79 — Mouth structural-region boundary

This is a planning boundary, not a new source component.

## Current real owner

`Mouth` is a real child owned by `HumanFace`, generated by `src/visual_engine/components/face/mouth.py:18-52`.
Its current geometry is one ellipse-like aperture with `semantic_region=MOUTH`.

## Future structural decomposition

```text
ORAL REGION
├── oral aperture
├── upper lip region
├── lower lip region
├── left commissure
├── right commissure
├── vermilion boundary
└── mental/chin transition
```

These are semantic regions for future work, not implemented children. The current Mouth leaf must not silently become seven owners.

## Proportion frame

Future mouth placement should be expressed relative to verified face/head landmarks and neighboring regions:

```text
eye band
   ↓
nasal region
   ↓
oral region
   ↓
mental/chin region
```

The exact numeric ratios are intentionally not declared in V1.79 because no calibrated reference campaign or independent placement consumer currently establishes them. The existing `mouth.center.y` remains the source of truth for current behavior.

## Boundary rule

The oral-region contract must eventually separate:
- mouth geometry from surrounding face surface;
- lip morphology from aperture geometry;
- commissures from external contour;
- chin/mental volume from mouth placement.

No renderer or COLOR rule is introduced by this planning document.
