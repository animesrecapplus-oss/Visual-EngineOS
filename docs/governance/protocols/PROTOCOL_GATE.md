# Protocol gate — V1.50

## Gate order

`G0 VERIFY → G1 ARCHITECT → G2 IMPACT → G3 IMPLEMENT → G4 HOSTILE → G5 REVIEW → G6 OPTIMIZE → G7 INTEGRATE → G8 VISUAL → G9 DOCUMENT → G10 PURGE → G11 CERTIFY`

## G0 — Verify

Read current status, roadmap, relevant component truth, prior decisions, current artifact policy and repository cleanliness.
Confirm the starting checkpoint and do not infer missing facts.

## G1 — Architect

Select one owner, one responsibility and one bounded change. Record non-responsibilities and compatibility constraints.

## G2 — Impact

Produce the affected consumer/dependency/contract/test/visual map. Re-open it when new facts appear.

## G3 — Implement

Change only the approved scope. Keep code within the file budget and add explanatory comments to logic.

## G4–G7

Run hostile tests, independent review, measured optimization and parent/child/system integration checks.

## G8 — Visual

Required only when output can change; otherwise document why visual evidence is not applicable.

## G9–G10

Freeze line maps, update decisions/status/history, generate current evidence, purge superseded generated contents.

## G11 — Certify

All applicable gates must be green, no blocked item may be hidden, the artifact tree must be clean, and the ZIP must match
the final workspace exactly.
