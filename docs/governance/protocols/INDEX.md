# Engineering discipline protocol index

All protocol files are bounded to 150 lines and are normative for future implementation bricks.

- `ARCHITECTURAL_IMMUNE_SYSTEM.md` — global lifecycle, roles and stop conditions.
- `COMPONENT_TRUTH_PROTOCOL.md` — component/subcomponent truth dossier and status semantics.
- `IMPACT_ANALYSIS_PROTOCOL.md` — mandatory multidirectional change-impact analysis.
- `HOSTILE_REVIEW_PROTOCOL.md` — adversarial attack families and review obligations.
- `VISUAL_EXECUTION_LOOP.md` — prompt→execution→inspection→correction loop.
- `NAMING_CLEANUP_PROTOCOL.md` — naming, duplication, line budget and cleanup rules.
- `TRACEABILITY_ID_PROTOCOL.md` — stable IDs and forward/backward traceability.
- `PROTOCOL_GATE.md` — ordered acceptance gates and certification rules.
- `IMPLEMENTATION_BRICK_MASTER_PROMPT.md` — reusable agent prompt for enforcing the complete discipline on every future brick.
