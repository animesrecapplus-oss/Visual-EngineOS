## Explicit non-goals

V1.25 does **not** implement:

- palettes;
- shadow or highlight models;
- ambient/key/fill/rim/bounce lighting;
- material response, roughness or metallic shading;
- transparency/transmission compositing;
- reflection response;
- style response;
- automatic gamut mapping;
- renderer-specific color management;
- generic 3D or ocular behavior.

## Definition of done

V1.25 is considered implemented only when the typed contract, inheritance/override
resolver, persistence round-trip, targeted invalidation tests, adversarial rejection
tests, visual source→resolution evidence, and repository test matrix all pass. No visual
artifact is treated as proof of production rendering quality by itself.
