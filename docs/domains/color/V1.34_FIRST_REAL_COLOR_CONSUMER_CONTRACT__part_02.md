## 12. Definition of done

The brick is complete only when:

1. the real production caller is statically proven;
2. the operation has explicit input/calculation/output spaces;
3. alpha semantics are explicit;
4. provenance/lineage/fingerprints are deterministic;
5. existing RGB visual behavior is regression-tested;
6. alpha-bearing colors are not silently stripped;
7. sibling isolation and invalidation remain correct;
8. visual runtime samples are generated and inspected;
9. A4–A10 release gates pass;
10. the next color operation remains separate until another real consumer is proven.
