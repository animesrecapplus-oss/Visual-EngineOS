## 15. Next step — V1.37 micro-scope

The next step is a **real-transformation discovery gate**, not an algorithm by default.

1. Re-run the production consumer graph against any newly introduced color-bearing code.
2. Require one concrete caller that changes a canonical color value.
3. Trace the exact call chain and ownership boundary.
4. Reject representation conversions, persistence, palette selection, renderer-only math and
   eye-reference analysis as false positives.
5. If no transformation exists, keep the runtime unchanged and record another audit checkpoint.
6. If exactly one exists, freeze its complete contract before coding: input/calculation/output
   spaces, alpha, bounds, neutral/extreme behavior, gamut, provenance, lineage, dependencies,
   invalidation, cache identity, determinism, rounding, performance, runtime samples and visual
   acceptance.
7. Implement one operation only.
8. Add adversarial tests before optimization.
9. Produce actual runtime samples and inspect them visually.
10. Re-run A4-A10, clean caches, regenerate release evidence, remove superseded current artifacts,
    and publish a ZIP only after the final hash/test/visual checks pass.
