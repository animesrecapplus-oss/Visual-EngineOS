## 11. Self-critique

### What was intentionally avoided

- no invented legacy COLOR consumer;
- no second color authority;
- no conversion through hexadecimal text merely for convenience;
- no material or lighting coupling;
- no geometry dependency hidden inside color identity;
- no alpha compositing;
- no “pretty” renderer behavior added to make the visual board look more complete.

### Issues found and corrected during implementation

1. The first test suite execution exposed a missing V1.31 documentation contract;
   the gate failed as designed and the contract was added before any PASS claim.
2. A test mutated a component hierarchy while keeping a stale `RuntimeGraph`;
   the repository's graph contract correctly rejected that state. The test was
   fixed to rebuild the graph rather than weakening the graph contract.
3. The single-process full suite exhibited a cumulative runtime stall in an
   existing morphology block. The affected tests were isolated and passed in
   fresh processes. The release evidence therefore records the limitation rather
   than converting a timeout into a fabricated PASS.
4. The visual board was manually inspected after generation; it was not accepted
   merely because its assertions passed.

## 15. Next V1.32 — micro-scope

The next brick must start with a **real source audit**, not with a guessed feature.

### Step 1 — inventory actual remaining COLOR consumers

Search the repository for:

- direct `AppearanceDomain.COLOR` consumers;
- `base_color`, `pattern`, `palette`, `contrast`, `saturation`, `vibrance`,
  `lightness`, `temperature` reads;
- renderer adapters that still consume raw hexadecimal color;
- any code that converts `ColorRGBA` back to sRGB before a semantic operation.

Classify each real caller as:

1. typed canonical color consumer;
2. compatibility-only consumer;
3. color transformation operation;
4. palette operation;
5. effect/lighting operation;
6. dead/unreferenced code.

### Step 2 — migrate only a genuine consumer

Pick the first real downstream caller whose semantics are understood. Do not
create a dummy consumer solely to increase the version number.
