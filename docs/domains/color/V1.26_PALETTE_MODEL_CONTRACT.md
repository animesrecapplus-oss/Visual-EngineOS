# V1.26 — Palette Model Contract

V1.26 defines a whole-palette, renderer-neutral authority. A palette contains zero
or more semantic slots: `primary`, `secondary`, `accent`, `detail`.

Each entry stores canonical linear-sRGB RGBA and, when authored, the exact sRGB
source representation. Palette source identity is `authored`, `inherited`, or
`generated`. Generated palettes require generator provenance and cannot claim
an authored representation.

A component owns at most one typed local palette authority. Inheritance uses the
nearest palette authority and one explicit policy: `LOCAL_WINS`, `INHERIT_WINS`,
or `REJECT_CONFLICT`. A blocking nearest authority cannot be bypassed by a more
distant ancestor. Missing slots remain unresolved; slots are never mixed between
authorities.

The palette fingerprint excludes geometry, transforms, materials, lighting and
unrelated siblings. Persistence verifies the fingerprint and rejects tampering.

V1.26 does not perform palette interpolation, alpha compositing, lighting, shading,
material response, reflection, transmission, gamut mapping, or style transforms.
