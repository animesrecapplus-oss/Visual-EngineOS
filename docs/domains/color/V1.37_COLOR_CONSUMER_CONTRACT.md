# V1.37 — COLOR Consumer Contract

**Checkpoint:** V1.37_COLOR_CONSUMER_AUDIT  
**Date:** 2026-09-25  
**Decision:** audit-only; no new runtime transformation

## Scope

V1.37 starts from the V1.36 downstream consumer graph and asks a stricter question:
which consumer actually changes color, and did a *new* path appear after V1.36?

The answer is precise: `src/visual_engine/runtime/effects.py` is the real production
consumer that applies a color transformation, but it delegates to the already-certified
`src/visual_engine/runtime/effect_color.py` operation `effect.color.srgb8-interpolation`.
The V1.36 certified runtime has no added/removed/changed production Python file in V1.37.
Therefore this operation is **pre-existing**, not a new V1.37 candidate.

## Existing transformation contract

- **Input space:** canonical linear-sRGB `ColorRGBA`.
- **Input representation:** `ColorRGBA`, unassociated alpha.
- **Calculation space:** encoded sRGB 8-bit RGB channels.
- **Output representation:** `ColorRGBA`.
- **Output space:** canonical linear-sRGB.
- **Alpha:** base alpha is preserved; effect color alpha is ignored; `VisualEffect.alpha`
  is the sole effect-strength control.
- **Bounds:** effect alpha is finite and in `[0,1]`.
- **Neutral:** alpha `0` is strict object-identity.
- **Extreme:** alpha `1` selects effect RGB and preserves base alpha.
- **Gamut:** no gamut mapping; interpolation remains in the encoded sRGB8 endpoint gamut.
- **Provenance:** source/effect identifiers are included in lineage.
- **Lineage:** immutable tuple.
- **Fingerprint:** operation/version/input/effect/result content participates in the digest.
- **Invalidation:** changing operation version, inputs, effect fingerprint, alpha or lineage
  changes the result fingerprint.
- **Cache:** no hidden mutable cache; fingerprint is suitable for an external deterministic cache.
- **Determinism:** fixed encoded-sRGB8 interpolation and Python `round` semantics.
- **Performance:** color values are materialized lazily and one effect color is decoded once
  for fill and contour.
- **Visual criterion:** preserve the established art-directed encoded-sRGB8 appearance;
  V1.37 must not silently replace it with linear-light blending.

## Promotion rule

Because no new transformation exists, V1.37 does **not** add another color operation,
new cache, new lineage model, or new color space. Adding one would be an invented feature
rather than an audit result.
