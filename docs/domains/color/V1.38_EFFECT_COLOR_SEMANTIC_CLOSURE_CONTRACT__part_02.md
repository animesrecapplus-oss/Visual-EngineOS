## 9. Versioning

RGB visual output remains governed by the existing V1.34 operation. V1.38 nevertheless
changes runtime **resolution identity** because fingerprint and lineage invalidation
semantics changed:

```text
ENGINE_VERSION     = 1.3.8  (unchanged)
SCHEMA_VERSION     = 2      (unchanged)
RESOLUTION_VERSION = 18 → 19
```

This is an invalidation/provenance contract change, not a new color-space algorithm.

## 10. Visual acceptance

The real runtime board must contain:

- very dark colors;
- mid tones;
- highlights;
- close colors;
- complementary colors;
- alpha-bearing colors;
- 0, 1, 2 and multiple effects;
- shadow→tint and tint→shadow cases.

The retained PNG is generated directly from `resolve_effects()`. Mathematical values are
not accepted without visual inspection.
