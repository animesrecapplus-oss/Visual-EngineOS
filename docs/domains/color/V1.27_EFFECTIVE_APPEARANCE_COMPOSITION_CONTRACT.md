# V1.27 — Effective Appearance Composition Foundations

## Purpose

V1.27 defines the first renderer-neutral composition boundary between the typed
BASE authority (V1.25) and the typed Palette authority (V1.26).

The word **composition** means deterministic semantic selection only. It does not
mean alpha compositing, color interpolation, lighting, shading, material response,
reflection, transmission, or style transformation.

## Contract

For one target component and one semantic role:

```text
BASE authority resolution ─┐
                           ├─ deterministic composition selection
Palette authority + slot ──┘
```

The composition result preserves both authorities' fingerprints/provenance. It
never creates a third hidden color authority.

## Semantic role mapping

V1.27 maps only these roles:

- `primary` → `primary`
- `secondary` → `secondary`
- `accent` → `accent`
- `detail` → `detail`

`background` and `custom` have no implicit Palette mapping. They fail closed
instead of silently falling back to `primary`.

## Modes

- `BASE_ONLY`: only a matching BASE role may resolve.
- `PALETTE_ONLY`: only the matching Palette slot may resolve.
- `BASE_THEN_PALETTE`: matching BASE wins; Palette is used only when BASE for that
  role is absent.
- `PALETTE_THEN_BASE`: matching Palette wins; BASE is used only when that Palette
  slot is absent.
- `REJECT_SAME_ROLE`: if both authorities claim the same role, resolution is
  rejected rather than silently selecting one.

These are explicit request policies. No hidden precedence exists.

## No mixing

The selected color is exactly the canonical color already owned by the selected
BASE or Palette authority. Alpha remains unassociated. No multiplication,
addition, interpolation, premultiplication, or compositing is performed.

## Provenance

The result retains:

- BASE fingerprint and authority component when present;
- Palette fingerprint and authority component when present;
- selected source (`base`, `palette`, `none`);
- selected Palette slot.

## Fingerprinting and invalidation

The composition fingerprint includes only:

- composition contract version;
- target identifier;
- explicit composition request;
- relevant BASE resolution identity;
- relevant Palette resolution identity;
- selected Palette slot.

It deliberately excludes geometry, transform, contour, material, lighting and
unrelated siblings.

## Failure rules

The resolver rejects or leaves unresolved when:

- a required authority is absent;
- a requested Palette slot is absent;
- a nearest authority blocks inheritance;
- an inheritance policy rejects a local conflict;
- a role has no explicit Palette mapping;
- the request itself is contradictory;
- typed and legacy Palette authorities coexist.

No fallback to another semantic slot is permitted.

## Non-goals

V1.27 does **not** implement:

- palette generation;
- shadows/highlights;
- ambient/key/fill/rim/bounce lighting;
- BRDF;
- metallic/roughness response;
- transmission compositing;
- reflection;
- style response;
- gamut mapping;
- renderer-specific post-processing;
- production color-management certification.
