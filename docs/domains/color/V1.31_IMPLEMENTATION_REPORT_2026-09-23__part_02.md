## 3. Fail-closed behavior tested

The implementation explicitly rejects:

- wrong domain passed to the COLOR resolver;
- missing typed COLOR role;
- typed role + second legacy COLOR authority;
- MATERIAL data entering the COLOR domain;
- LIGHTING data entering the COLOR domain;
- contradictory `appearance_role_bridge` dependency fingerprint;
- tampered `TypedColorInput` fingerprint;
- invalid upstream role contribution.

There is **no legacy COLOR fallback** in V1.31. This is intentional: migrating an
unknown or invented downstream consumer would create a false architectural claim.

## 4. Color-space semantics

The resolver consumes the V1.24 canonical representation:

- linear-sRGB RGB channels in `[0,1]`;
- unassociated alpha in `[0,1]`;
- no premultiplication;
- no clipping;
- no gamut mapping;
- no alpha compositing.

The alpha-bearing visual sample uses a checkerboard only as a display aid. The
runtime value remains RGBA with its original alpha.
