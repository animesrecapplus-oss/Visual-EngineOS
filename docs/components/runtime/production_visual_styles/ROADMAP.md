# Roadmap

V1.61 extracts the existing renderer-facing production style-map responsibility from `ProductionRenderSession.render_face`.

No new appearance algorithm, COLOR consumer, renderer algorithm, geometry behavior, occlusion rule, database schema,
cache owner or persistence semantics are planned by this brick.

Next version must begin with a fresh read-only audit of the certified V1.61 checkpoint and must prove a new real owner,
consumer and contract before any further extraction or extension.
