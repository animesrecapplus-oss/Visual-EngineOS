# Decisions — CMP-FACE-VIS-001

- `DEC-FVIS-001`: treat the reported visual defects as a real calibration gap, not as a renderer-only QA issue.
- `DEC-FVIS-002`: exact eye/ear center alignment is the HumanFace default aesthetic; it is not enforced globally.
- `DEC-FVIS-003`: shorten/lower the default nose bridge and move the mouth down rather than changing the generic placement engine.
- `DEC-FVIS-004`: replace the flat hairline with a tapered silhouette, side locks and bounded optional strand detail.
- `DEC-FVIS-005`: preserve the hair/ear optical relation by keeping side-lock overlap in the same hair depth layer.
