# Contracts — CMP-FACE-VIS-001

- `CON-FVIS-001`: default eye and ear centers share the same local Y coordinate.
- `CON-FVIS-002`: default nose bridge begins at or below eye-center Y.
- `CON-FVIS-003`: default nose tip remains separated from mouth top by at least `0.08` local units.
- `CON-FVIS-004`: hair geometry has a non-flat hairline and optional detail strands.
- `CON-FVIS-005`: hair detail density is bounded in `[0,1]` and deterministic.
