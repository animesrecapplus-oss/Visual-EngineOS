# Roadmap — CMP-FACE-EAR

## V1.56

Implemented one production ear family, two-child cardinality, renderer role/depth contract, cache invalidation, persistence round-trip and visual output.

## V1.80

Implemented and certified strict numeric/finite input hardening at the existing leaf owner. No new semantic Ear child was created.

## Deferred

Inner-ear topology, cartilage morphology, earrings/accessories, material/light behavior, hair interaction and ear-specific occlusion remain separate future micro-components. They are not implemented by V1.80.
