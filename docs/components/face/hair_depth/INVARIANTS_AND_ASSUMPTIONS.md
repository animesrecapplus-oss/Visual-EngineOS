# Invariants and assumptions

`INV-HD-001`: Hair depth is finite and represented by the existing integer depth metadata contract.

`INV-HD-002`: Hair depth is strictly in front of Ear depth for the certified production face: `1 > 0`.

`INV-HD-003`: the depth value does not change Hair geometry coordinates or fingerprint semantics beyond the existing generated geometry contract.

Assumption: the current V1.58 production face uses Hair as the foreground cap where it overlaps the ears.

Boundary: detailed 3D hair volume and strand-level depth remain deferred.
