# Guarantees and status — CMP-FACE-HAIR

Guarantees:
- deterministic finite closed cap geometry;
- explicit ownership and semantic region;
- cache-visible parameter changes;
- generic visual visibility control;
- persistence round-trip of authored Hair data.

Not guaranteed:
- realistic hair strands;
- calibrated human hair morphology;
- hair/ear occlusion;
- accessory interaction;
- expression-driven hair deformation.

Status: CERTIFIED V1.57.
Final certification must be recorded only after all gates complete.
