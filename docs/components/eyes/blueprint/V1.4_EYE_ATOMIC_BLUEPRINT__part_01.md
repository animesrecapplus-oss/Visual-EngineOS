# V1.4 — Eye Deepening: atomic and subatomic blueprint

> This document is the planning baseline after A10. It does **not** claim that a stream is complete because a few atoms are implemented. Every atom must pass the same development → test → artefact → visualisation → correction → validation discipline before acceptance.

## 1. Objective

The eye remains the reference component. The objective is to transform the remaining sketches into a measurable parameter language capable of producing clean default eyes and very large controlled variation across morphology, expression, colour, camera, style, interaction and prompt-driven authoring.

## 2. What was already present

The audit found substantial foundations already implemented: parametric eye families, bilateral pair construction, pupil/gaze containment, explicit eyelid curves/folds, upper/lower lashes, brow constraints, structured highlights, expression presets, renderer-neutral geometry, camera-frame transforms, appearance contracts, visibility/coverage and deterministic cache/provenance infrastructure. These are treated as **atomic evidence**, not as completion of the broader workstreams.
