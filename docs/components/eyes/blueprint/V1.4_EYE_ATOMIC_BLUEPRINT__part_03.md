## 4. Cross-workstream relationships

```text
Prompt
  ↓
Visual IR / provenance
  ↓
Identity + morphology + style + state + expression + gaze
  ↓
Eye pair / constraints / semantic regions
  ↓
Geometry (eye, lid, iris, pupil, lashes, brow, highlights)
  ↓
Occlusion / interaction / depth
  ↓
Appearance (colour + material + lighting + reflection)
  ↓
Camera / shot / LOD
  ↓
Renderer-neutral artefacts
  ↓
SVG / raster evidence
  ↓
Visual review + correction + acceptance
```

### 4.1 Dependencies that must remain explicit

- Morphology defines geometric limits; it must not silently absorb style, colour or camera semantics.
- Gaze determines ocular assembly placement and may drive lid deformation, but does not redefine intrinsic morphology.
- Expression is an intent layer. It composes changes across lids, brows, gaze, pupil/iris exposure, highlights and states without becoming a second morphology system.
- Colour/appearance consumes geometry/material/light context; it must not mutate geometry unless an explicit material/optical contract says so.
- Camera transforms intrinsic geometry into presentation space; zoom/crop must not alter identity or intrinsic morphology.
- Occlusion is a relation/consequence layer; coverage must not be confused with opacity.
- Style is a transformation/prior layer and must not fork the entity model into unrelated duplicate eye implementations.
- Prompt compilation must produce explicit, inspectable intermediate parameters and provenance rather than renderer conditionals.
- Variation is constrained generation: it must combine continuous/discrete axes while enforcing anatomical/geometric/aesthetic validity.

## 5. The common component contract

Every future eye subcomponent and, later, every non-eye component should expose the same conceptual envelope:

`Identity → Morphology → Geometry → Transform → Appearance → State → Expression → Relations/Constraints → Provenance → Version → Cache identity → Renderer contract → QA evidence`

No subcomponent is accepted if one of these boundaries is silently encoded in an unrelated layer.
