# V1.4 — Eye authoring precedence

1. **Explicit user intent** controls authorable parameters and visibility.
2. **Default aesthetic policy** fills unspecified values for coherent output.
3. **Domain contracts/invariants** reject unsafe or mathematically invalid geometry.
4. **Renderer rules** serialize the already-resolved geometry/visibility and must not
   silently reinterpret author intent.

This keeps the engine opinionated enough to produce a clean default eye without making
its aesthetic preferences mandatory. “Default” means “when the user did not specify”,
not “the user is forbidden to change it”.
