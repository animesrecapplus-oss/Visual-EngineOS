# 3. Repère canonique à donner au moteur

Pour éliminer les mots vagues comme « grand », « énorme », « décalé », etc., toutes les grandeurs morphologiques doivent être définies dans un repère local invariant par translation et rotation.

Soient :

- `I` = centre du canthus interne nominal ;
- `O` = centre du canthus externe nominal ;
- `W = ||O-I||` = largeur morphologique de référence ;
- `e = (O-I)/W` = axe longitudinal ;
- `n = (-e_y, e_x)` = normale 2D ;
- `M = (I+O)/2` = milieu de l'œil.

Pour tout point `P`, ses coordonnées normalisées sont :

`u(P) = dot(P-I, e) / W`

`v(P) = dot(P-M, n) / W`

Ainsi, la rotation de tout l'œil ne modifie pas ses valeurs `u,v`.

Le canthus interne est `u=0`, le canthus externe `u=1`.

**Toutes les métriques morphologiques ci-dessous doivent être exprimées dans ce repère.**

# 4. Définition exacte de « grand », « petit », « énorme »

Un mot d'ordre du moteur : **aucune taille qualitative sans ratio explicite**.

## Taille d'un élément circulaire/elliptique

Pour un élément d'aire `A_e`, définir une taille équivalente :

`D_eq = 2 * sqrt(A_e / pi)`

Puis utiliser le ratio :

`size_W = D_eq / W`

ou, pour une composante contrôlée par la hauteur de l'œil :

`size_H = D_eq / H_ref`.

## Tiers d'ingénierie initiaux

Ces tiers sont des **conventions de moteur**, pas des vérités anatomiques :

- `small` : `size_W < 0.35`
- `medium` : `0.35 <= size_W < 0.50`
- `large` : `0.50 <= size_W < 0.65`
- `very_large` : `0.65 <= size_W < 0.80`
- `extreme` : `size_W >= 0.80`

Ils devront être validés composant par composant. Une pupille « large » et un highlight « large » ne doivent pas partager nécessairement les mêmes seuils.
