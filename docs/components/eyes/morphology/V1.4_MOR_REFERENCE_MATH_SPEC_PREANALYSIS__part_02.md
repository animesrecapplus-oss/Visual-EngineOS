# 5. Définition exacte de « décalé »

Pour un élément centré en `C_e`, son décalage par rapport à une référence `C_r` est :

`dx = dot(C_e-C_r,e)/W`

`dy = dot(C_e-C_r,n)/W`

`d = sqrt(dx^2 + dy^2)`.

Tiers d'analyse :

- `centered` : `d <= 0.02`
- `subtle` : `0.02 < d <= 0.05`
- `moderate` : `0.05 < d <= 0.10`
- `strong` : `0.10 < d <= 0.20`
- `extreme` : `d > 0.20`

Pour une pupille, cette définition doit être appliquée **par rapport au centre de l'iris**, et non au centre géométrique de l'œil.

Une seconde métrique est alors nécessaire :

`d_iris = ||C_pupil-C_iris|| / R_iris`

Cette valeur est bornée par le contrat de containment de la pupille.

# 6. Envelope de l'œil

Les deux courbes principales sont :

- `U(t)` pour la paupière supérieure ;
- `L(t)` pour la paupière inférieure ;
- `t in [0,1]`, avec `t=0` à l'intérieur et `t=1` à l'extérieur.

Définir la séparation normale :

`g(t) = v(U(t)) - v(L(t))`.

Selon l'orientation choisie, on impose `g(t) >= 0` pour l'ouverture visible.

La hauteur d'ouverture maximale :

`G_max = max_t g(t)`.

Ratio d'ouverture :

`open_ratio = G_max / W`.

La position de l'ouverture maximale :

`t_open = argmax_t g(t)`.

C'est une variable distincte de `open_ratio`.

Deux yeux de même largeur et de même ouverture peuvent donc différer par `t_open`.

# 7. « Œil rond » n'est pas synonyme de « ouverture grande »

Pour éviter une future variable fourre-tout, le moteur doit distinguer au minimum :

`aspect_ratio = W/H_ref`

`open_ratio = G_max/W`

`t_open = argmax g(t)`

et une mesure de symétrie de l'ouverture :

`A_L = integral_0^0.5 g(t) dt`

`A_R = integral_0.5^1 g(t) dt`

`opening_balance = (A_R-A_L)/(A_R+A_L)`.

Ainsi :

- `opening_balance = 0` : ouverture équilibrée ;
- `opening_balance > 0` : plus d'ouverture du côté externe ;
- `opening_balance < 0` : plus d'ouverture du côté interne.

# 8. Familles morphologiques

Les mots « amande », « rond », « étroit », etc. doivent être des **classes dérivées d'un vecteur de mesures**, jamais des dessins codés en dur.

Vecteur minimal :

`F = [W/H_ref, open_ratio, t_open, opening_balance, end_angle_inner, end_angle_outer, upper_curvature, lower_curvature]`.

## 8.1 Amande

Propriété structurale : ouverture positive, point de largeur maximale généralement interne à l'intervalle, avec convergence des deux extrémités.

Le moteur doit tester les mesures, pas comparer un nom.

## 8.2 Rond / doll

Caractérisé par un `open_ratio` élevé **et** une enveloppe verticale importante. Le critère ne doit pas être `open_ratio` seul.

## 8.3 Étroit

Caractérisé par un `open_ratio` faible par rapport à `W`, sans nécessiter de réduire proportionnellement toutes les courbures.

## 8.4 Upturned / downturned

Définir une pente globale morphologique par la différence de position des attaches externes et internes, dans le repère local :

`delta_end = v(C_outer_mid) - v(C_inner_mid)`.

Et non par la rotation globale du repère de l'œil.

# 9. Courbure : définition exacte

Pour une courbe paramétrique `P(t)=(x(t),y(t))`, la courbure signée 2D est :

`kappa(t) = (x'(t)y''(t)-y'(t)x''(t)) / (x'(t)^2+y'(t)^2)^(3/2)`.

Une mesure sans unité utile :

`K_bar = W * integral |kappa(s)| ds / L`.

Pour détecter une pointe artificielle de canthus, une simple mesure de `kappa_max` ne suffit pas. Utiliser aussi une **concentration de courbure** :

`C_rho = integral_0^(rho L) |kappa(s)| ds / integral_0^L |kappa(s)| ds`.

Une forte valeur de `C_rho` signifie qu'une grande partie du changement de direction se produit dans une très petite portion du bridge.

Une future règle « anti-triangle » peut ainsi être formulée quantitativement, au lieu de dire « la courbe doit être douce ».
