# 10. Canthus interne / externe

Le canthus n'est pas un triangle de fermeture.

Il doit être modélisé comme un bridge local `B_i(s)` ou `B_o(s)` avec `s in [0,1]`.

Mesures obligatoires :

- `L_b/W` = longueur d'arc normalisée ;
- `theta_0` = angle tangent au départ ;
- `theta_1` = angle tangent à l'arrivée ;
- `Delta_theta` = changement d'orientation total ;
- `K_bar_b` = courbure moyenne normalisée ;
- `C_rho` = concentration de courbure ;
- `monotone_v` = signe constant de `dv/ds` sauf dégénérescence explicitement déclarée.

## Critère géométrique anti-pointe

Le bridge ne doit pas être accepté uniquement parce que ses extrémités sont C1.

Il faut aussi empêcher un profil dont la variation tangentielle est concentrée près d'une extrémité.

Le moteur devra donc calculer `C_rho` pour une petite fenêtre `rho` et comparer cette mesure à une bande calibrée par QA visuelle.

# 11. Epicanthic fold : définition séparée

L'epicanthic fold ne doit **jamais** être le mécanisme de fermeture du contour.

Le pli est une courbe distincte `E(s)` dans le voisinage médial.

Définitions :

- `s in [0,1]` du haut vers le bas ;
- `v(E(s))` strictement monotone ;
- `u(E(s))` reste dans une fenêtre médiale bornée ;
- aucun point du pli ne doit devenir un endpoint de `U`, `L`, `B_i` ou `B_o`.

Amplitude latérale :

`A_ep = max_s |u(E(s))-u_ref|`.

Longueur normalisée :

`L_ep/W`.

Courbure : `K_ep` calculée avec la même définition de `kappa`.

## Principe visuel converti en invariant

Le pli doit être une **courbe longue et progressive**, pas un segment court dont la seule fonction est de fermer le canthus.

On doit donc vérifier :

1. longueur minimale relative ;
2. variation monotone de `v` ;
3. courbure non concentrée dans un seul sommet ;
4. séparation topologique du contour ;
5. amplitude latérale bornée.

Les limites numériques précises d'`L_ep/W`, `A_ep` et `C_rho` doivent être calibrées sur une campagne dédiée avant d'être déclarées normatives.

# 12. Séparation canthus / cils

Dans les références, une pointe visuelle peut venir du canthus **ou** d'un cil.

La responsabilité doit être mesurable.

Définir une projection `P_can` de la géométrie sans cils et `P_lash` de la géométrie des cils.

Une pointe externe présente dans `P_lash` mais absente de `P_can` est un effet de cil, pas un effet de morphologie du canthus.

Le test doit donc vérifier l'indépendance : modifier `lash_extension` ne doit pas modifier `B_o`.

# 13. Upper / lower lid : indépendance structurelle

Il faut distinguer les contrôles :

`U(t)` et `L(t)` sont deux courbes indépendantes.

Une future variation de `upper_curve` doit laisser inchangées, hors contraintes explicitement déclarées :

- `L(t)` ;
- `iris` ;
- `pupil` ;
- `eyebrow` ;
- `epicanthic fold`.

La relation autorisée est l'interaction locale par les canthi, pas la contamination globale.

# 14. Référence A : décalage pupillaire effectivement mesuré

Pour les cellules où contour et pupille étaient séparables, le décalage horizontal du centre de la pupille par rapport au centre de la composante de contour était approximativement dans :

`dx/W ≈ -0.246 ... +0.208`.

Le décalage vertical mesuré dans cette segmentation était approximativement :

`dy/W ≈ +0.102 ... +0.307`.

Ces valeurs sont **des mesures de la planche et de sa segmentation**, pas des limites de gaze.

Elles montrent néanmoins que le moteur ne doit pas supposer `C_pupil = C_eye`.

# 15. Ce que les images ne permettent PAS de déduire exactement

Pour éviter l'hallucination :

- les images ne fournissent pas les points de contrôle Bézier d'origine ;
- les images ne donnent pas directement une profondeur 3D ;
- les images ne permettent pas d'identifier avec certitude chaque petit trait comme une structure anatomique ;
- la seconde planche contient des éléments graphiques qui empêchent une segmentation naïve fiable ;
- aucune valeur anatomique universelle ne doit être déduite de ces dessins d'anime.

La bonne stratégie est donc : **mesurer ce qui est mesurable, définir mathématiquement ce qui doit l'être, puis calibrer le moteur par QA**.
