# V1.4 — MOR envelope metrics contract

## Scope

This contract formalizes the measurable envelope layer proposed from the two supplied eye reference sheets. It does **not** generate or repair geometry. It measures the final resolved upper/lower lid samples already owned by the eye geometry builder.

The layer supports the existing atoms `MOR.shape_family`, `MOR.aspect_ratio`, `MOR.opening`, `MOR.upper_curve`, `MOR.lower_curve`, `MOR.rotation`, `MOR.resolution`, `MOR.morph_bounds`, and future morphology comparison/variation work. It is deliberately not a duplicate geometry solver.

## Canonical local frame

Let `I` and `O` be the semantic inner and outer canthus points and `W = ||O-I|| > 0`.

`e = (O-I)/W`

`n = (-e_y, e_x)`

For any point `P`:

`u(P) = dot(P-I,e)/W`

`v(P) = dot(P-I,n)/W`

`u=0` is the inner canthus and `u=1` the outer canthus. Ratios built from `u,v` are invariant under translation, rotation and uniform scale.

## Envelope height and aspect ratio

`H = W * (max(v) - min(v))` over both lid curves.

`aspect_ratio = W/H` when `H > 0`. For the explicit closed/covered degenerate representation (`H=0`), aspect ratio is **undefined** and the API returns `None`; infinity is not used as a fake finite metric.

This is a projected local height, not the world-Y bounding-box height.

## Opening profile

Upper and lower curves must be sampled in the same order (`inner -> outer`) and with equal sample counts.

For paired samples:

`g(t_i) = v_lower(t_i) - v_upper(t_i)`.

For the declared eye orientation, positive `g` is the visible aperture. The implementation treats the sampled curves as piecewise-linear for metric integration; this is explicit and avoids pretending to know an unobserved analytic curve between samples.

`G_max = max(g) * W`

`opening_ratio = G_max/W = max(g)`.

`opening_area = W * integral_0^1 g(t) dt`.

`opening_area_ratio = opening_area/W = integral_0^1 g(t)dt`.

`opening_max` uses the first maximum sample when the maximum is tied. For a zero/degenerate opening, `t_open=None` because there is no unique opening maximum.

## Opening balance

`A_L = W * integral_0^0.5 g(t)dt`

`A_R = W * integral_0.5^1 g(t)dt`

`opening_balance = (A_R-A_L)/(A_R+A_L)` when the denominator is positive; otherwise it is `0` by definition.

The integral is split at `t=0.5` even when the number of samples is odd. This avoids a hidden dependence on sample parity.

## Apex metrics

The upper apex is the first sample minimizing `v_upper`; the lower apex is the first sample maximizing `v_lower`.

Both `t` position and local `u,v` coordinates are exposed. `u` is the geometrically meaningful normalized longitudinal position; `t` is the position in the existing sampled parameterization.

## Validity / fail-closed behavior

The metric layer rejects malformed inputs rather than repairing them. It requires:

- finite points;
- equal upper/lower sample counts, at least two;
- finite, non-zero canthus width;
- endpoint `u` coordinates consistent with the supplied canthi within a scale-aware tolerance;
- no materially negative aperture gap (`min_gap < -tolerance` fails the report).

The function never modifies a point.

## Important nonclaims

The metrics do not prove biological/anatomical correctness, anime-style correctness, C1 continuity, 3D correctness, perspective correctness, or visual equivalence to the reference images. They are a common numerical language for comparing resolved geometry with reference measurements.

The numeric category thresholds discussed in the reference analysis (`small`, `large`, `extreme`, etc.) are **not** encoded here. They require a separate calibration dataset and must not be smuggled into the measurement layer as universal truths.
