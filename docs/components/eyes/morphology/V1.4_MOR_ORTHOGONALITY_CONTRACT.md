# V1.4 — MOR.morph_orthogonality contract

## Definition

`MOR.morph_orthogonality` is a **causal-scope contract**. It does not mean that two
parameters produce identical pixels, and it does not mean mathematical orthogonality
of a continuous parameter basis. It means that each morphology parameter is permitted
to alter only explicitly declared semantic geometry channels.

The proof compares geometry projections, not rendered-image similarity.

## Semantic channels

The current contract separates:

- upper/lower lid margins;
- inner/outer canthus endpoints;
- inner/outer canthus bridges;
- upper/lower creases;
- iris geometry;
- pupil geometry;
- epicanthic-fold geometry.

Separating endpoint from bridge is essential: changing a lid curve may legitimately
change the tangent used to construct its adjacent bridge without moving the opposite
anatomical endpoint.

## Legitimate dependencies

- `width`, `height`, `opening`: global morphology dimensions may scale dependent ocular geometry;
- `rotation_deg`: a global rigid transform may move every geometric channel;
- `upper_curve`: upper margin, upper crease and the tangent-dependent canthus bridges;
- `lower_curve`: lower equivalents;
- contour wave/irregularity: lid margins/creases and their bridge tangents;
- inner/outer canthus controls: their own endpoint/bridge plus the endpoint-attached fold where applicable;
- `epicanthic_fold`: fold geometry only.

A particularly important invariant is that contour wave/irregularity must not move the
iris/pupil merely because sampled contour bounds changed. Internal offsets therefore use
the nominal morphology frame.

## Proof method

For each parameter a non-zero perturbation is applied to a controlled baseline. The solver
is run twice and each semantic projection is compared exactly. Any changed channel outside
the declared set is contamination and fails the contract. A perturbation that changes no
channel also fails because a dead parameter is not an implemented parameter.

This proof is intentionally stronger than “the image looks almost unchanged”.

## Nonclaims

This does not prove biological independence, statistical independence, global parameter
manifold orthogonality, or independence under every future expression/camera/occlusion
solver. Those require their own contracts.
