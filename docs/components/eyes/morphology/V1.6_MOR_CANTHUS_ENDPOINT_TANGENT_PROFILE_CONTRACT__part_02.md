## Next brick

The next brick should address the **closure representation itself**, not add more tangent scalars.
It should investigate a geometry-owned terminal/bridge profile that can taper or converge toward
one point without producing a full-width vertical cap, while preserving the renderer-neutral
contract.

That work must include:

1. explicit terminal topology (shared point versus finite gap);
2. stroke-width-aware visual envelope diagnostics;
3. anti-cap and anti-hook guards;
4. upper/lower termination ownership;
5. preservation of C1 where a finite bridge remains;
6. exact behavior when the corner gap tends to zero;
7. comparison at normal and close-up framing;
8. sampled cubic/path evidence;
9. regression against V1.4/V1.5 outputs;
10. reference digitization before any numeric style band is promoted.
