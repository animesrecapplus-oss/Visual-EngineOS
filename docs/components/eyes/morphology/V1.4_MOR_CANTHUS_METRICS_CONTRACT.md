# V1.4 — MOR CanthusMetrics Contract

## Scope

`CanthusMetrics` measures one already-resolved cubic canthus bridge. It does not generate,
repair, smooth, serialize or classify the bridge as anatomically correct. It is a measurement
layer used to challenge the existing geometry against explicit mathematical properties and
future digitized reference curves.

The bridge is `B(t)`, `0 <= t <= 1`, with cubic control points `P0..P3`. `P0/P3` are the
resolved bridge endpoints. The eye frame is the same inner→outer frame used by
`EnvelopeMetrics`: `e=(O-I)/||O-I||`, `n=(-e_y,e_x)`.

## Primary quantities

### Chord and transition length

`C = ||P3-P0||`.

Arc length is not assumed to have a closed elementary form. It is evaluated numerically from
`L = integral_0^1 ||B'(t)|| dt` with a fixed 128-point Gauss-Legendre quadrature. The implementation
therefore reports both `arc_length` and `arc_to_chord_ratio = L/C`, plus `normalized_arc_length = L/W`.

### Endpoint tangent angles

For endpoint derivatives `T0=B'(0)` and `T1=B'(1)`, local tangent angles are:

`theta_i = atan2(T_i·n, T_i·e)`.

`net_turn_angle` is the shortest signed angular difference in `[-pi, pi)`.

### Curvature

For `B(t)=(x(t),y(t))`:

`kappa(t) = (x'(t)y''(t)-y'(t)x''(t)) / ||B'(t)||^3`.

The absolute total turning is:

`K_abs = integral_0^1 |kappa(t)| ||B'(t)|| dt`.

The normalized mean absolute curvature is:

`K_bar = W * K_abs / L`.

The peak is also exposed in raw and normalized form (`max_curvature`, `W*max_curvature`).

### Turning simplicity

`turning_efficiency = |net_turn| / K_abs`, clamped to `[0,1]` numerically.

A simple one-direction bend approaches 1. A curve whose tangent rotates substantially more than
its endpoint-to-endpoint angular change has lower efficiency. This is diagnostic evidence for
loops, over-turning or other non-simple bridge behavior; it is not by itself an aesthetic rule.

### Curvature concentration

The fraction `endpoint_curvature_fraction_20` is the fraction of `K_abs` accumulated within the
first 20% and last 20% of the measured arc length. The `half_turn_window_ratio` is the smallest
sampled arc interval carrying 50% of `K_abs`, divided by total arc length.

The primary integrals do not depend on this diagnostic sampling density. Distribution diagnostics
use a deterministic odd sample count (default 257) and are tested for convergence. The fixed 128-point
quadrature was selected after an independent 128-vs-256 node accuracy challenge across current bridge
families; the observed maximum difference was below `6e-10` in the tested primary integrals. This is
an empirical numerical validation, not a formal universal error bound for arbitrary future cubics.

### Chord deviation

For each sampled bridge point, perpendicular distance to the endpoint chord is measured. The
maximum divided by `C` is `max_chord_deviation_ratio`.

This is the explicit geometric quantity for the visual idea of a “third-side” or bulging closure.
It does not assert that a large deviation is bad: some legitimate stylized curves need it.

## Quantitative triangular-closure evidence

`triangle_evidence` is a bounded diagnostic index, not a reference classifier. It combines four
independent signals:

1. endpoint curvature concentration;
2. curvature peak relative to mean curvature;
3. loss of turning efficiency;
4. normalized maximum chord deviation.

Each signal is monotonically normalized to `[0,1]` before a geometric mean is taken. The current
normalization constants are deliberately treated as **diagnostic calibration constants**, not
normative aesthetic limits. They must be recalibrated when digitized reference curves become
available.

A controlled pointy cubic is required to score materially above a rounded quarter-arc in tests.
That proves the detector responds to the intended synthetic contrast without claiming that a
particular engine bridge is aesthetically wrong.

## Validity and failure policy

- all control points and semantic canthi must be finite;
- semantic canthi must define a non-zero eye axis;
- bridge endpoints must define a non-zero chord;
- every sampled derivative must remain non-zero;
- sample count must be odd and at least 33;
- integration tolerance must be finite and positive;
- the function never repairs malformed input: it raises `ValueError`.

## Reference comparison policy

The two supplied anime reference sheets establish visual families (almond, round/doll, narrow,
upturned/downturned and related stylizations), but their original vector curves are unavailable.
Therefore no numeric “anime truth range” is invented here. Current engine metrics are recorded by
family and can be compared directly once curves are digitized from the references.

## Nonclaims

This contract does not prove biological anatomy, artistic quality, C2 continuity, 3D geometry,
style equivalence, or reference matching. It also does not replace `MOR.continuity`; continuity
owns endpoint attachment/C1 bridge construction, while this module measures the resulting bridge.
