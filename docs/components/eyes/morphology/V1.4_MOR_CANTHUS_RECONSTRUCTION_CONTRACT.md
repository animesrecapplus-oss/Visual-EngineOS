# V1.4 — MOR Canthus reconstruction micro-brick

## Scope

This brick corrects one specific geometric defect exposed by `CanthusMetrics`: the previous
fixed topological floor forced zero/low roundness canthi to have a visible vertical separation
between upper and lower margin endpoints. In rendered anime-style eyes this produced a small
triangular/cap-like termination before any curvature analysis was even applied.

This brick therefore changes **only endpoint separation**. It does not yet claim a complete
reference-curve reconstruction, epicanthic anatomy, or an anime/realistic style match.

## Mathematical policy

For each canthus, `roundness = r` is dimensionless and constrained to `[0, 0.2]`.
The requested vertical half-gap is:

`q = half_width * r`.

The resolved half-gap is:

`R = min(0.35 * half_height, max(q, 0.02 * min(half_width, half_height)))`.

The `0.02` floor is a robustness constant. It was selected by a deterministic adversarial sweep
of the current generator over 9 shape families, openings, 4 contour resolutions and strong
cardinal/diagonal gaze. Floors below it failed at least one tested low-sample/low-opening case;
`0.02` passed the full direct geometry matrix. This is an empirical robustness result, not a
universal theorem and not an anatomical measurement.

The endpoint pairs remain:

- inner upper `(-half_width, -R_inner)`;
- inner lower `(-half_width, +R_inner)`;
- outer upper `(+half_width, -R_outer)`;
- outer lower `(+half_width, +R_outer)`.

Inner and outer values are resolved independently.

## Invariants

1. All inputs are finite.
2. `half_width > 0` and `half_height > 0`.
3. Both roundness values are in `[0, 0.2]`.
4. `0 < R <= 0.35 * half_height`.
5. Increasing one roundness cannot decrease its own resolved half-gap.
6. Changing inner roundness cannot change outer endpoints, and vice versa.
7. The public bridge remains a four-control-point cubic, preserving the current renderer-neutral
   geometry contract while this micro-brick is introduced.
8. The existing C1 continuity and closed-contour topology gates remain mandatory.

## Why this is a reconstruction step

The old policy imposed a constant geometric separation even when the author explicitly requested
zero roundness. That was not a faithful parameter interpretation. The new policy makes the authored
roundness control the actual visible corner scale, with only a small topology floor required by the
current non-degenerate C1 representation.

This does **not** solve the remaining curvature-distribution problem. `CanthusMetrics` still exposes
endpoint curvature concentration in some families. The next geometry brick must address tangent/
curvature profile rather than increasing or hiding tolerances.

## Visual evidence policy

Every acceptance run produces:

- legacy `before` SVG/PNG;
- reconstructed `after` SVG/PNG;
- actual 33-sample bridge overlays;
- magnified corner diagnostics;
- a deterministic manifest containing geometry/metric hashes;
- a separate timing file so timing noise cannot alter deterministic identity.

The final eye render is inspected separately from the diagnostic overlay. A sampled overlay is not
considered a visual success merely because the sample points are mathematically valid.

## Nonclaims

This brick does not prove biological anatomy, does not digitize the supplied reference sheets,
does not claim a universal anime threshold, and does not close `MOR.epicanthic_fold` or the
remaining curvature-profile work.
