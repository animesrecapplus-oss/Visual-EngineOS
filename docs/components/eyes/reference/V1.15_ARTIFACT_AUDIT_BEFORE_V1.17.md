# V1.15 artifact audit before V1.17 cleanup

Before deleting the superseded V1.15 artifact directory, the useful evidence was
recorded in the V1.15 documentation and reviewed for relevance to the alignment
fix.

## Retained conclusions

- `pair_forward_backward.png`: demonstrated that individual eye yaw states were
  independent; no V1.17 geometry source is taken from the pixels.
- `yaw30...`, `yaw60...`, `yaw89...`, `yaw90...`, `yaw120...`, `yaw150...`,
  `yaw180...`: retained as historical evidence of the pre-V1.17 spherical/depth
  behavior, not as calibration truth.
- `__depth_sampled.png` diagnostics: established that stored 3D samples were
  available for depth QA, but they are not reference images.
- `manifest.json` and `V1.15_EVIDENCE.txt`: retained as historical provenance.

## Why they are removed now

V1.17 changes the ownership contract of alignment rotation. Keeping the old PNGs
inside the active `artifacts/` directory would make them easy to mistake for
current release evidence. The useful conclusions are preserved here and in the
V1.15 contract/log; the active artifact directory is therefore cleaned before
V1.17 release verification.
