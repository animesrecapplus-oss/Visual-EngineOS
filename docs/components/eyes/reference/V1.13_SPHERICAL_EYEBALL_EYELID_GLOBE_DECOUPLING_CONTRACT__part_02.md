## 11. Multiple eyes

Every eye may carry an independent `ocular_yaw_deg` and `ocular_pitch_deg`.
Pair-level identity remains a separate policy. Therefore these are legal in the
free multi-eye model:

```text
left  = forward
right = backward
third = upper-right
```

The human-default pair policy still controls bilateral structural differences.

## 12. Projection invariants

The implementation must maintain:

1. finite coordinates;
2. finite orientation values;
3. orthonormal ocular basis;
4. non-zero globe radius;
5. `pupil_radius < iris_radius < globe_radius`;
6. no perspective camera on/inside the globe;
7. no internal surface promoted from back-facing to visible;
8. no V1.13 yaw/pitch insertion into the generic 2D transform matrix;
9. no mutation of the eyelid contour to simulate globe rotation;
10. deterministic output for identical inputs.

## 13. Compatibility

`EyeParameters.rotation_deg` remains the public roll channel. V1.13 adds yaw and
pitch fields without changing the positional meaning of existing `LocalTransform`
arguments; new runtime ocular fields are appended after the existing transform
fields.

The eye generator version is incremented from `2` to `3` because the geometry
cache must not reuse geometry generated before the spherical view-axis contract.

## 14. Visual QA

The V1.13 QA produces clean SVG/PNG renders and separate sampled PNG diagnostics.
Sampled points are taken from the stored projected iris geometry and mapped through
the actual SVG `viewBox`.

The QA matrix includes:

- front;
- yaw 30/60/89.9/120/180;
- pitch ±60;
- combined yaw/pitch/roll;
- combined yaw/pitch/roll/alignment;
- forward/backward binocular asymmetry.

A sampled diagnostic is evidence that the stored geometry is rendered where the
engine says it is. It is not reference-pixel calibration.

## 15. Reference boundary

V1.11 reference candidates remain pending explicit human approval. Therefore V1.13
does not create a source-reference overlay and does not promote any reference
measurement into a MOR style band.

## 16. Testing

The dedicated V1.13 test module covers:

- orthonormality across adversarial yaw/pitch ranges;
- edge-on and back-facing visibility;
- real 3D iris projection;
- pitch foreshortening;
- roll/basis semantics;
- alignment-axis separation;
- parent basis composition;
- runtime exposure;
- eye-generator integration;
- single-eye backward gaze;
- multiple independent eyes;
- perspective camera safety;
- renderer integration;
- finite/dense projection output.

The full repository suite is also required before checkpoint promotion.

## 17. Known non-goals

This brick does not claim:

- a complete anatomical eyeball;
- a non-spherical sclera;
- a physically accurate cornea;
- optical refraction;
- true chamber depth;
- 3D facial skin/orbit geometry;
- physically exact eyelid sliding on a globe;
- automatic identification of near/far canthi from pixels;
- human-anatomy inference from the V1.11 reference sheet.

These omissions are intentional acceptance boundaries, not hidden TODOs presented as
finished behavior.
