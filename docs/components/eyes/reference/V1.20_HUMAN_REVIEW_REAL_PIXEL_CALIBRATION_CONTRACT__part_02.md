## 7. Error fields

For every actually tested `follow_strength`, V1.20 records:

- upper mean error;
- upper RMS error;
- upper maximum error;
- lower mean error;
- lower RMS error;
- lower maximum error;
- inner-upper tangent error;
- outer-upper tangent error;
- inner-lower tangent error;
- outer-lower tangent error;
- medial-terminal error;
- lateral-terminal error.

No strength that was not actually evaluated is interpolated or extrapolated.

## 8. Endpoint tangent correction

During implementation review, the existing overlay comparator contained a subtle bug:
when evaluating the outer endpoint, it constructed the reference tangent tip from the
first reference point instead of the actual outer endpoint.

V1.20 corrects this. The outer tangent now starts from the stored outer terminal.

This is an important example of the V1.20 self-critique requirement: a plausible
numerical value is not accepted merely because the function executes successfully.

## 9. Calibration gate

At least two independent approved samples are required.

The aggregate only uses strengths present in every approved sample. The candidate is
selected from values that were actually measured.

The result is always:

`candidate_only`

Numerical minimization does not promote an engine default.

## 10. Visual acceptance gate

Before promotion, the candidate must be inspected visually against the actual source
and through engine renders. The following remain hard review axes:

- no triangular eyelid/canthus artifact;
- no terminal discontinuity;
- no canthus drift;
- no floating globe;
- no detached iris/pupil;
- upper/lower continuity;
- positive and negative alignment;
- independent roll;
- independent yaw/pitch;
- bilateral asymmetry;
- narrow opening;
- closure;
- extreme orientations;
- real aperture clipping;
- depth ownership.

A lower RMS is not sufficient for acceptance.
