## 12. MOR promotion gate

`mor_ranges()` requires at least **two independently approved samples**. Its `confidence`
field is explicitly a **sample-coverage score**, not a statistical confidence interval and
not an anatomical truth probability.

A range record contains:

```text
observed_min
observed_median
observed_max
confidence
source_sample_count
confidence_definition
```

A single reference can therefore describe an observed sample but cannot define a promoted
style range.

## 14. Nonclaims / rejected shortcuts

- No candidate box is an eye merely because it resembles one.
- No upper/lower component is selected automatically.
- No terminal is inferred from black-pixel extrema.
- No medial/lateral role is guessed from screen X in oblique views.
- No caruncle is inferred from pink pixels.
- No epicanthus is inferred from an unlabelled dark stroke.
- No bilateral symmetrisation is applied to source measurements.
- No single sample becomes a style distribution.
- No overlay is rendered against an unapproved source region.
