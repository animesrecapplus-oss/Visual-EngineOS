# V1.14 Artifact Audit Before V1.15 Cleanup

Date: 2026-09-19

Before replacing the V1.14 generated artifact directory with V1.15 evidence, the useful visual and structural conclusions were recorded here.

## Useful evidence retained

- V1.14 yaw 30/60/89.9/120/180 renders: spherical internal surfaces progressively foreshorten and disappear toward the rear hemisphere.
- V1.14 offset-pupil sampled render: pupil remains an iris child after the V1.13 detachment correction.
- V1.14 mixed yaw/pitch/roll/alignment render: inherited orientation remains coherent.
- V1.14 forward/backward pair: each eye resolves independently.
- V1.14 closed-eye render: aperture/opening remains the final blink gate.

## Limitation discovered

The V1.14 depth information was not yet a true depth-ordered surface contract. The lid traces were lifted to 3D, but visibility was still principally a 2D aperture measurement. This is the specific gap closed by V1.15.

## Cleanup rule

The old `artifacts/v114_eyelid_globe_coupling/` directory may be removed after this audit because the conclusions above, plus the V1.14 contract and implementation log, preserve the engineering evidence without retaining superseded generated output.
