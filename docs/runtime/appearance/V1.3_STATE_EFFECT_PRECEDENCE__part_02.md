### Multiple shadows

For shadow alpha, independent scalar contributions combine as:

```text
A = 1 - Π(1 - A_i)
```

This prevents simple addition from exceeding 1 and is order-independent for the scalar coverage value. Color compositing still follows deterministic priority order.

## Separation rules

The following concepts remain distinct:

```text
State       = semantic condition
Effect      = external visual consequence
Occlusion   = visibility/coverage consequence
Shadow      = illumination/color consequence
Visibility  = whether the component can contribute
Opacity     = contribution strength
```

A state is therefore not allowed to mutate renderer pixels directly.

## Current boundary

Implemented here:

- deterministic state precedence;
- exclusive groups;
- explicit conflicts;
- fixed-point requirements;
- duplicate-state resolution;
- complete state decision provenance;
- generic typed visual effects;
- deterministic effect ordering;
- typed composition laws;
- targeted effects;
- effect provenance;
- legacy shadow compatibility through a generic effect;
- PostgreSQL schema for states/effects/bindings.

Not claimed:

- geometric intersection;
- polygon clipping for occlusion;
- contact detection;
- shadow casting from real geometry;
- transmission/refraction;
- state-to-appearance compilation;
- transition animation between states.

Those require later geometry/optics/animation contracts.
