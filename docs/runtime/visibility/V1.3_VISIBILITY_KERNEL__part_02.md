## 12. Semantic affected-region events

The kernel emits `AffectedRegionEvent` records containing:

- target ID;
- semantic region ID;
- occluder ID;
- event kind;
- geometric coverage;
- residual visibility;
- transmitted visibility;
- depth relation;
- intersection area.

Downstream systems can therefore react to:

```text
iris covered 37%
```

without the visibility kernel knowing what an iris is or what consequence that
should have.

## Numerical / topology boundary

This is a robust **2D computational-geometry kernel**, not a final production
renderer. The current explicit boundaries are:

- ellipses/circles are approximated by deterministic polygons;
- Bézier paths are not yet accepted as area primitives by this kernel;
- no 3D perspective, z-buffer or volumetric visibility;
- no refraction or physical optical simulation;
- subpixel rasterization/anti-aliasing belongs to the rendering backend;
- pathological floating-point input still requires QA around tolerance policy.

The use of a dedicated boolean backend is intentional: reimplementing a mature
polygon topology engine inside the visual engine would create a large, fragile
maintenance surface with no benefit to the visual-language architecture.

## QA checkpoint

The test suite covers:

- primitive conversion;
- overlapping union;
- concave intersection;
- difference with holes;
- multiple occluders;
- overlapping occluders without double counting;
- behind-target geometry;
- transparent/transmitting coverage;
- structured semantic events;
- deterministic boolean results.

The full suite passes at this checkpoint.
