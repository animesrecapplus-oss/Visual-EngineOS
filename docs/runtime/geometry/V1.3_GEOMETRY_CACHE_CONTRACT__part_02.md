## Initial benchmark checkpoint

On the current development environment, a 200-component synthetic scene measured approximately:

```text
cold 200 builds: 15.783 ms
hot  200 hits:    8.219 ms
observed speedup: 1.92x
```

This is a diagnostic benchmark, not a production guarantee. The measurement also exposes
an important future optimization target: dependency-key construction itself currently has
non-zero cost because fingerprints are recomputed from the graph. Before declaring cache
performance production-grade, graph-level fingerprint/index reuse should be benchmarked and,
if justified by profiling, introduced without weakening invalidation correctness.
