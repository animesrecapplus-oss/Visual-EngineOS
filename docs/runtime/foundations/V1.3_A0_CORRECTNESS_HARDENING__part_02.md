## 4. What A0 deliberately does NOT claim

- no production anatomical eyelid solver;
- no biological iris/cornea model;
- no physical Fresnel/refraction model;
- no true projected shadow solver;
- no production facial-expression solver;
- no complete brow morphology system;
- no complete lash morphology system;
- no complete pupil morphology/exposure system;
- no complete iris microstructure system;
- no quantitative perceptual visual-regression system;
- no live PostgreSQL end-to-end runtime closure.

The eye remains the reference/stress component, not the definition of the generic
architecture.

## 5. Residual architecture debt intentionally retained

`RuntimeGraph` is a compiled graph/index structure over mutable `Component` objects.
The safe lifecycle is therefore:

```text
authoring mutation
    ↓
rebuild RuntimeGraph
    ↓
resolve/cache/render
```

The current API does not prevent a caller from mutating a component after compilation.
This is documented as a lifecycle contract rather than silently introducing a deep-copy
or hidden synchronization policy. A future immutable authoring snapshot may strengthen
this boundary, but it is not part of A0 because it would be a broader API/identity change.

The PostgreSQL layer also remains intentionally identified as unfinished. The current
schema/repository surface is not allowed to masquerade as full source-of-truth runtime
integration.
