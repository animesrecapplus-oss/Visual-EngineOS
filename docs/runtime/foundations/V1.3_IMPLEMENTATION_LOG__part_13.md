## V1.4 — MOR.morph_orthogonality + visibility/performance overlay checkpoint

### Audit before implementation

The repository already had generic occlusion/coverage and several feature-local `enabled`
flags, but it did **not** have a canonical hierarchical eye-granularity visibility
contract. The existing performance history contained cache benchmarks, but it did not
record per-artifact geometry-build/SVG-render/PNG-raster timings as a separate history
layer. `MOR.morph_orthogonality` was still only `PARTIAL_OR_SKETCH`.

The audit also found a real morphology coupling: iris/pupil offsets were normalized against
*sampled contour bounds*. Therefore contour wave/irregularity could move internal ocular
parts even when their own parameters were unchanged. This was corrected by using the nominal
morphology frame for internal offsets.

### Implemented

- `src/visual_engine/components/face/eyes/morphology/orthogonality.py` — canonical
  parameter→semantic-channel contract and executable contamination report.
- `src/visual_engine/components/face/eyes/morphology/spec.py` — `epicanthic_fold` parameter.
- `src/visual_engine/components/face/eyes/geometry/types.py` — `epicanthic_fold_points`.
- `src/visual_engine/components/face/eyes/geometry/contour.py` — local endpoint ownership
  and C1-safe endpoint handling.
- `src/visual_engine/components/face/eyes/geometry/lid_follow.py` — C1-safe gaze window and
  rotation-aware deformation; no X-only re-anchoring after rotation.
- `src/visual_engine/components/face/eyes/geometry/builder.py` — nominal reference frame
  for iris/pupil offsets and explicit epicanthic-fold geometry.
- `src/visual_engine/components/face/eyes/visibility.py` — canonical hierarchical visibility tree.
- `src/visual_engine/components/face/eyes/appearance/spec.py` — visibility contract attached to
  appearance without entering geometry identity.
- `src/visual_engine/render/svg.py`, `eye_svg_contours.py`, `eye_svg_primitives.py`,
  `eye_svg_effects.py` — consume visibility and serialize geometry-owned canthus/fold data.
- `tools/performance_metrics.py` — timing helper kept outside deterministic artifact manifests.
- `tools/visual_qa_v14_mor_orthogonality.py` — deterministic morphology evidence plus separate
  performance timing history.

### Visibility semantics

The tree covers the eye, sclera, contour/lids/canthi/epicanthic fold, eyelid creases, iris
subgranularities, pupil/effects, highlights/reflections, lashes, brows and sclera/under-eye
marks. `false` on a parent recursively disables descendants; sibling nodes remain independent.
This is the contract required for future prompt phrases such as “without pupils” without
incorrectly disabling highlights or lashes. Free-form prompt parsing itself remains partial.

### User-authoring precedence

The project defaults are explicitly classified as aesthetic coherence defaults, not immutable
artistic commands. Explicit user parameters/visibility take precedence. Hard geometry/math
invariants remain non-overridable for safety.

### Performance history overlay

Timing is intentionally **not** mixed into deterministic SVG/PNG manifests. Each visual QA
run records geometry build, SVG serialization, PNG rasterization, total case time and artifact
byte sizes in `performance_timing.json`. A chronological `performance_history.jsonl` can then
be compared across checkpoints without making reproducibility depend on machine scheduling.

### Tests / evidence

- `tests/unit/test_v14_morphology_orthogonality.py`: semantic-channel perturbation, canthus
  independence, epicanthic-fold isolation and hierarchical visibility tests.
- Existing continuity suite revalidated after endpoint/gaze changes.
- Existing V0.9/V1.1 rendering tests revalidated; one smoke test was made selector-specific
  because geometry-owned cubic canthus bridges legitimately introduced additional cubic paths.

### Nonclaims

This closes `MOR.morph_orthogonality` and the explicit epicanthic-fold geometry atom only. It
does not close `MOR.morph_variation`, the free-form prompt compiler, iris microstructure,
biological epicanthic anatomy, production performance, or a claim that all future ocular
subfeatures are already rendered.
