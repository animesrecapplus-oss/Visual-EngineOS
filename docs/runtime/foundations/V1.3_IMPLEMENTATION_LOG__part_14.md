### Final V1.4 MOR orthogonality validation — 2026-09-16

The implementation was challenged against the existing V1.4 continuity and rendering suite,
not just the new tests. Several real coupling/architecture defects were found and corrected:

- sampled contour bounds were removed from the reference frame used for iris/pupil offsets;
- inner/outer canthus ownership was separated from opposite-corner spline controls;
- gaze-follow now uses a zero-value/zero-first-derivative window and preserves rotated canthus
  endpoints without the previous X-only re-anchoring bug;
- sharp canthi use a scale-relative topological floor so a mathematically degenerate zero-gap
  cubic bridge cannot loop; the visible effect remains a very small rounded floor rather than
  an invalid self-intersecting closure;
- the exact round-shape circular-envelope behavior was preserved after the endpoint-ownership
  refactor;
- the SVG renderer was kept renderer-neutral with respect to visibility and geometry ownership;
- a pre-existing smoke-path test was narrowed to the actual white smoke path because geometry-
  owned C1 canthus bridges legitimately introduced additional cubic paths.

Final full suite: **449 passed, 1 skipped in 17.10s** (450 collected; the skip is the live
PostgreSQL integration requiring `VISUAL_ENGINE_POSTGRES_DSN`).

A4/A5/A6/A7/A8/A9 direct gates were rerun. A5 current baseline is intentionally updated to
manifest SHA `af6d8bcc792a72b31c11239adb80240d3e4945b0ed5074ffd61100c4d20c1729`, while the

## V1.4 functional brick — MOR formal envelope metrics — 2026-09-17

### Objective

Implement the next small step from the mathematical reference analysis: a canonical numerical
measurement layer for the ocular envelope. The brick intentionally does **not** modify the eye
shape generator. It makes “large”, “narrow”, “open”, “asymmetric” and related future language
measurable through dimensionless local-frame quantities rather than qualitative labels.

### Audit before implementation

The existing code already had `EyeParameters.width/height/opening`, shape families and
`EyeGeometry.nominal_width/visible_height`, so a second geometry implementation would have
been duplication. No canonical `EnvelopeMetrics` owner or paired-lid opening integral was
found. Existing `aspect_ratio` and `opening` atoms were therefore formalized by measurement,
not reimplemented as geometry parameters.

### Implementation

- `src/visual_engine/components/face/eyes/morphology/envelope.py` — **L1-L220**.
  Canonical `EnvelopeMetrics` dataclass, invariant inner→outer local frame, projected height
  and aspect ratio, paired-lid gap profile, exact piecewise-linear area integration including
  odd-sample half-interval splitting, opening balance, deterministic tie handling for `t_open`,
  upper/lower apex metrics and lid-depth balance. The function is observational: it never
  repairs geometry. Closed/zero-height envelopes report `aspect_ratio=None` rather than fake
  infinity.

### Mathematical choices / anti-false-positive decisions

1. The local frame uses `e=(O-I)/||O-I||` and `n=(-e_y,e_x)`, so dimensionless metrics are
   invariant to translation, rotation and uniform scale.
2. Height is measured in the local normal direction, not the world-Y bounding box.
3. Opening is `g(t)=v_lower(t)-v_upper(t)` for paired inner→outer samples.
4. Opening area uses the declared piecewise-linear interpolant. The implementation splits the
   integral at `t=0.5` even when the sample count is odd.
5. A zero-height closed/covered representation has no unique opening maximum; `t_open=None`.
6. Rotation can create ulp-level ties in the discrete maximum. A tiny relative tie tolerance
   resolves only numerical ties; it is not an aesthetic smoothing parameter.
7. Lower-lid endpoint `u` values are intentionally not required to equal 0/1 because the
   existing canthus geometry permits a local medial/lateral inset. Only semantic upper canthi
   anchor the metric frame.
8. The resolution matrix is a stress observation, not a false promise of resolution invariance.
The current round-eye generator has measurable coarse-sampling sensitivity at low opening; the
metric layer records it instead of hiding it with an arbitrary tolerance.
