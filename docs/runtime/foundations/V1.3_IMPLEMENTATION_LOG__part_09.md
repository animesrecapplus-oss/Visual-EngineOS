## V1.3 — A9 adversarial/property hardening + responsibility refactor — 2026-09-16

### Audit before implementation

The A8 checkpoint was inspected before A9 changes. Existing tests already covered several cycles, stale graph
checks, geometry-cache identity, transforms and visibility invariants. A9 was therefore not duplicated. Two
concrete weaknesses were reproduced: `stable_digest()` stringified mapping keys (allowing semantic key aliases)
and cyclic containers reached recursion failure; additionally the three largest ocular/render/cache modules
mixed facade and implementation responsibilities.

### Implementation and rationale

1. Added `src/visual_engine/components/common/canonical.py` as the model-safe canonicalization owner. It rejects
   cyclic values, non-finite floats and non-string mapping keys before JSON encoding.
2. Kept `runtime/canonical.py` as a compatibility import, avoiding a runtime dependency cycle into the model.
3. Updated `runtime/versioning.py` to use the strict canonicalizer for every stable digest.
4. Hardened `components/common/geometry_contract.py` against recursive metadata and key coercion.
5. Added cache-key validation and dependency-ID validation before cache state mutation.
6. Split `components/face/eyes/core.py` into `definitions.py` (domain types/solvers), `geometry_builder.py`
   (construction) and a small compatibility facade. Public historical imports remain valid.
7. Split SVG specialized code into `eye_svg_primitives.py`, `eye_svg_effects.py`, and `eye_svg_contours.py`;
   `render/svg.py` now owns public document assembly.
8. Split geometry-cache fingerprinting into `runtime/geometry_fingerprint.py`, leaving cache concurrency and
   eviction policy in `runtime/geometry_cache.py`; legacy public imports remain available through wrappers.
9. Added `tests/unit/test_v13_a9_adversarial.py` with deterministic adversarial cases across canonicalization,
   graph cycles, relation permutation, mutation, invalidation, concurrency, metadata and degenerate transforms.
10. Added `tools/verify_a9_adversarial.py` with required-file and facade line-budget guardrails plus focused test
    execution.
11. Added `tools/__init__.py` and configured pytest `pythonpath=[".", "src"]` so repository-local verification
    modules resolve consistently under the supported pytest entry points.
