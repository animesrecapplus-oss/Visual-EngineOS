## Transform resolution

Every component has a local 2D transform:

- x;
- y;
- rotation;
- scale_x;
- scale_y;
- z.

World 2D transform is the matrix composition of the hierarchy. The implementation retains the composed matrix instead of reconstructing a TRS decomposition.

Depth is separate:

```text
component_world_z = sum(local z)
geometry_world_z = component_world_z + geometry.local_z
```

This remains a 2D/hierarchical depth coordinate, not 3D perspective or geometric occlusion.

## Visibility / opacity / occlusion

These remain distinct:

```text
visibility != opacity != occlusion
```

Visibility and opacity currently compose multiplicatively through the hierarchy. The renderer-neutral 2D visibility/occlusion kernel is implemented separately and consumes resolved geometry; this generic component contract does not absorb that kernel's domain-specific geometry operations.

## State

Enabled local state-layer names are merged with externally supplied active-state names and sorted deterministically.

State precedence/conflict handling is now owned by the explicit state-policy resolver. V1.3 still does **not** claim anatomical state deformation or transition animation.

## Shadow

Shadow is an external visual effect. The current generic resolver can shade fill and contour colors from an externally supplied shadow alpha/color without mutating source contracts.

This is not a physical shadow solver.

## Determinism

Visual and geometry identities use canonical JSON and SHA-256. Python's process-randomized `hash()` is not used for persistent identity.

Cross-process canonical serialization remains a separate hardening gate; A3 establishes deterministic canonicalization and its accepted-value domain but does not falsely claim cross-process execution evidence here.
