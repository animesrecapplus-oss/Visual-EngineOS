## V1.3 — A5 reproducible visual QA closure — 2026-09-16

**Status: implemented and verified.**

### Pre-check: existing implementation audit

Before writing a new QA system, the A4 checkpoint was inspected. `tools/qa_a0_closure.py` already
implemented deterministic generation for the three A0 brow/state cases and produced a manifest.
Therefore that implementation was retained as A0 evidence rather than duplicated. The audit also
confirmed that `docs/runtime/foundations/V1.3_VISUAL_QA_VERDICT__part_01.md` (split document; see adjacent parts) described a larger feedback matrix while the complete
`artifacts/history/v1.3/qa_feedback/` source script and manifest were absent. This is the exact A5 gap.

### What was implemented

1. Added `tools/scripts_visual_qa_v13_feedback.py` as the sole source of truth for the full ocular
   visual-regression matrix. It uses public geometry and SVG rendering APIs and CairoSVG for PNG output.
2. Added `tools/verify_a5_visual_qa.py`. It rejects missing sources, manifest drift, stale/unlisted
   outputs and nondeterministic clean generations.
3. Added four static integrity tests in `tests/unit/test_v13_a5_visual_qa.py`.
4. Regenerated `artifacts/history/v1.3/qa_feedback/` from a clean directory: 44 SVG + 44 PNG = 88 evidence files.
5. Recorded SHA-256 identities in `manifest.json` and execution/source hashes in `artifacts/A5_EVIDENCE.txt`.
6. Preserved the reference-oriented cases as explicitly documented visual targets, not claims of
   external pixel-identical reconstruction.
7. Added comments at the non-obvious ownership/invariant points: stale-output cleanup, controlled
   variable axes, public API usage, bilateral-side semantics, and non-self-referential manifests.
