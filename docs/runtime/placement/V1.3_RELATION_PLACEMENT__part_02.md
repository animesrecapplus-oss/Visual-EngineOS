## Failure policy

The integration fails closed for:

- missing graph endpoints;
- malformed placement metadata;
- unknown placement keys;
- unsupported relation types carrying placement declarations;
- missing source/target anchors;
- missing required target region maps;
- missing region anchors when `target_anchor_scope=region`;
- incompatible constraints already rejected by `PlacementIntent`;
- coordinate-frame mismatch already rejected by `resolve_placement()`.

No automatic center, scale, direction, category-specific attachment or camera
transform is invented.

## Current boundaries

Implemented:

- relation metadata → validated placement specification;
- relation endpoints → `PlacementIntent` endpoints;
- explicit semantic target region selection;
- explicit component-vs-region anchor scope;
- graph-wide deterministic placement resolution;
- reuse of the existing renderer-independent placement solver;
- no implicit placement for ordinary relations;
- fail-closed validation;
- stable relation-resolution identity for the current in-memory contract.

Not implemented:

- natural-language prompt → placement declaration;
- automatic anchor generation;
- automatic target-region selection from names or fuzzy semantics;
- surface-normal/contact solving;
- collision and penetration solving;
- multi-constraint optimization;
- placement deformation;
- 3D/perspective placement;
- persisted relation IDs;
- placement-specific cache key integration;
- automatic execution of the resulting `PlacementSolution` into a scene graph;
- automatic invocation of the visibility kernel after placement.

Those are separate contracts and remain explicit future work.
