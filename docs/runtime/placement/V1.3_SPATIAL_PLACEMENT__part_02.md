## Separation from visibility

Placement does **not** decide which target regions are affected.

After placement:

```text
resolved source geometry
        ↓
boolean visibility kernel
        ↓
semantic region intersection
        ↓
AffectedRegionEvent
```

This preserves the separation:

```text
WHERE IS THE OBJECT?
        ≠
WHAT DOES IT OCCLUDE?
```

## Example class of problems

A target may have a resolved geometry whose dimensions change with morphology. A dependent source may then be positioned using an explicit relative dimension or coverage constraint.

The placement solver does not need to know whether the target is an eye, face, hand, wheel, window, leaf, building surface or any future component.

Likewise, the source can be any positive-area geometry. The solver does not need to know whether it is a frame, hair mass, finger, bandage, object or another component.

## Current boundaries

Implemented:

- explicit anchor references;
- anchor-based placement;
- relative dimensions;
- uniform and non-uniform dimension scaling;
- arbitrary numeric offset;
- arbitrary rotation;
- geometric coverage target under uniform scale;
- deterministic coverage search;
- explicit depth relation;
- renderer-independent affine solution.

Not yet implemented:

- relation graph integration that automatically discovers placement requests;
- semantic directional intents such as `top`, `bottom`, `diagonal` as a prompt-language layer;
- surface-normal/contact placement;
- 3D placement and perspective;
- collision/penetration resolution;
- multi-constraint optimization;
- deformation of the source or target to satisfy placement;
- automatic morphology inference from natural language;
- persistence schema for placement intents;
- automatic prompt compilation.

These are deliberately not approximated by object-specific conditionals.

## QA

The test suite covers:

- anchor alignment under scale and rotation;
- relative dimensions independent of pixel resolution;
- non-uniform dimension constraints;
- rejection of inconsistent uniform constraints;
- measured geometric coverage solving;
- rejection of invalid coverage anchors;
- rejection of ambiguous dimension+coverage combinations;
- deterministic point transformation from the resulting solution.

The full project suite passes at this checkpoint.
