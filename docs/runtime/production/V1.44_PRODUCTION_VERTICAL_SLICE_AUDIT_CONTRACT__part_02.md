## 12. Trigger for the next implementation

The next runtime implementation is unlocked only by a real production entry
point that owns an end-to-end request.

The next step must then establish, before adding broad orchestration:

1. request/shot/frame ownership;
2. component graph ownership;
3. generic resolution invocation;
4. geometry generation invocation;
5. spatial transform invocation;
6. renderer invocation;
7. destruction/teardown boundary;
8. exact cache lifetime, if a cache is actually needed;
9. visual acceptance criteria on the real produced asset.

Until that trigger exists, V1.44 remains an architectural audit checkpoint.
