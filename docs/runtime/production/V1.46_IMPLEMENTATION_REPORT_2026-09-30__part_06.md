## 21. Performance and optimization review

### What was optimized

The primary V1.46 optimization was not a micro-optimization. It was avoiding an unnecessary
partitioning layer and avoiding duplicated appearance authorities.

The production path continues to reuse:

- `ResolutionCache` single-flight behavior;
- `GeometryCache` single-flight behavior;
- content-based geometry identity;
- `ResolutionFingerprint.cache_identity`;
- caller-owned lifetime boundaries.

### What was deliberately not optimized

No new:

- persistent cache;
- global cache;
- scene/frame manager;
- cache partitioning;
- byte budget;
- render-output cache;
- COLOR transform;
- speculative geometry cache dimension.

The measured workload did not justify them.
