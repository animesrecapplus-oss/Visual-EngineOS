# V1.46 — next micro-scope

V1.46 should **not** immediately add another orchestration abstraction. The first real slice
now exists and must be strengthened before being generalized.

### 1. Generalize request ownership without hiding lifetime

- decide whether `ProductionRenderSession` remains the permanent API or becomes a thin
  component of a broader render-request abstraction;
- preserve explicit `close()` semantics;
- test nested/parallel sessions;
- test two simultaneous independent roots;
- test shared versus partitioned caches using actual sessions, not synthetic cache loops;
- measure LRU pressure under those real workloads before changing cache policy.

### 2. Complete appearance ownership for the first slice

- determine exactly which existing appearance layers can be projected into `VisualContract`
  without bypassing COLOR contracts;
- do not teach the renderer to parse legacy appearance payloads;
- if a real gap exists, extend the generic appearance bridge rather than adding face-specific
  color logic;
- produce visual before/after evidence for any such change.

### 3. Expand face geometry honestly

The current production slice explicitly renders only:

```text
HumanFace
 ├── head       rendered
 ├── left eye   rendered
 ├── right eye  rendered
 ├── nose       not yet generated
 ├── mouth      not yet generated
 ├── ears       not yet generated
 └── hair       not yet generated
```

V1.46 should select **one** missing family only, preferably the next component whose generic
geometry contract is already mature enough to avoid another synthetic abstraction.

For that component:

- add deterministic geometry parameters;
- add generator registration;
- add dependency declaration if needed;
- add visual QA;
- connect it to the same production session;
- verify occlusion/order rather than simply drawing it on top.

### 4. Occlusion must become a real production concern

The next non-trivial visual risk is that the current slice has almost no occlusion.
Before adding many components, V1.46 should test:

- semantic region ownership;
- front/back ordering;
- overlapping eye/head regions;
- mask behavior;
- fail-closed unsupported masks;
- visual regression under rotations.
