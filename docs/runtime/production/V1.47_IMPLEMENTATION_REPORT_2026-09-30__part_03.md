### 12.3 Full repository matrix

There are 111 test files and 956 collected tests.

The repository was executed in 12 isolated batches of at most 10 files. Every batch completed:

- 955 passed;
- 1 expected skip (`tests/integration/test_postgres_vertical_slice.py` without

historical morphology process-state interaction can hang when unrelated files share one pytest
process. The isolated batch strategy preserves the complete file inventory while avoiding a false
PASS from a timed-out aggregate process.

## 19. Next step — V1.48 micro-plan

V1.48 must not immediately add mouth, ear or hair.

The first question is whether the current production graph already contains a second real overlap.
If it does not, the correct action is another audit/contract step, not synthetic geometry.

If a second real overlap exists, V1.48 should:

1. reuse the exact V1.47 semantic region boundary;
2. prove multiple front occluders;
3. validate exclusive vs shared coverage;
4. validate dominant depth under reversed ordering;
5. validate behind/coplanar relations;
6. validate transmission only for a real material;
7. compare attribution with actual render order;
8. measure 1/2/N occluder performance;
9. determine whether a visibility cache or spatial index is justified;
10. define visibility-region fingerprint/invalidation only when a mutable producer requires it;
11. repeat all session/cache/stale/determinism/visual tests;
12. keep COLOR frozen.

Physical 3D/z-buffer work remains deferred until an actual production requirement demonstrates that
semantic 2D depth is insufficient.
