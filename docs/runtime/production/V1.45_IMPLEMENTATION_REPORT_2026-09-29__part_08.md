### 5. Performance

Use the real production session to measure:

- cold render;
- warm render;
- two simultaneous sessions;
- multiple component instances;
- geometry-cache bytes;
- resolution-cache entries;
- eviction rate;
- rebuild frequency;
- teardown time.

Do not introduce a new cache manager or byte budget unless those measurements demonstrate a
specific problem.

### 6. COLOR rule remains unchanged

COLOR remains **frozen unless a real V1.46 consumer demonstrates a missing contract**.
No speculative COLOR V1.46 subproject should be created.

### 7. Acceptance gate

V1.46 should be accepted only if:

```text
real production consumer remains real
visual artifact is manually inspected
no component is silently omitted
unsupported geometry fails closed
cache lifetime remains explicit
stale graph remains protected
teardown remains clean
existing eye regression remains green
COLOR boundary remains intact
```
