## 10. Visual QA

The board was generated from actual runtime output.

The ocular renderer was invoked through the existing public renderer API to produce
`V1.44_RENDERER_LIBRARY_SAMPLE.svg` and its raster preview.

The board explicitly labels this as:

> REAL renderer output — library API sample, NOT a production call

This distinction is intentional. The board demonstrates that the renderer still
produces coherent visual output while simultaneously proving that no production
caller exists.

The board was manually inspected after generation. The first layout was found to
have text overlap in the evidence boxes; the layout was corrected and the board
was regenerated. The final board has no text overlap in the architecture boxes.

## 13. Exact implementation files and responsibilities

### `tools/audit_v144_production_vertical_slice.py`

AST inventory of all 172 production Python files.

Responsibilities:

- resolve aliases;
- exclude local definitions from external consumer counts;
- inventory audited call sites;
- inventory public exports;
- detect ambiguous star imports;
- detect dynamic import/eval/exec surfaces;
- classify A8 separately;
- emit the authoritative JSON finding.

### `tools/benchmark_v144_production_vertical_slice.py`

Runs the audit in five clean subprocesses and records wall-clock timing.

### `tools/visual_qa_v144_production_vertical_slice.py`

Runs two clean A8 verifications, generates the actual renderer sample, rasterizes
it, builds the explanatory board and removes temporary evidence directories.

### `tools/verify_v144_production_vertical_slice.py`

Fail-closed certification gate. It checks the audit result, ambiguity checks,
scene dependency direction, cache identity contract, resolution version and
COLOR boundary.

### `tests/unit/test_v144_production_vertical_slice.py`

Six tests cover the audit-only decision, zero external resolver/render/entity /
geometry owners, scene dependency direction, A8 classification and export-vs-call
separation.
