## 20. Historical test migration

V1.42 and V1.43 contained assertions that deliberately required **zero** production
`ResolutionCache` owners and **zero** production resolver consumers.

Those assertions were correct at their historical checkpoints but became stale when V1.45
created the first real owner.

They were updated to assert the new invariant:

```text
only src/visual_engine/runtime/production_slice.py is the current production owner
```

The historical reports and checkpoints remain unchanged and continue to record the earlier
zero-consumer state.

Modified tests:

- `tests/unit/test_v142_resolution_cache_lifetime.py`;
- `tests/unit/test_v143_production_consumer_audit.py`.
