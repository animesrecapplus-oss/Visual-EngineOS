## 9. Authored face presentation correction

`build_human_face()` already contained a legacy `AppearanceLayer` for skin, but generic
`resolve_component()` consumes `VisualContract`, not legacy appearance-layer color payloads.

Rather than teaching the new renderer to inspect legacy appearance layers, the entity builder
now declares an explicit authored `VisualContract`:

```text
fill      #d9a77d
contour   #6b4030
```

This is an authored presentation value. It is not a COLOR transform or conversion.

File:

`src/visual_engine/entities/face.py`

Affected lines:

```text
2
11-16
```

## 10. First visual implementation — rejected

The first generated PNG was inspected manually.

It showed only the head and iris/pupil points. The eye aperture geometry was mathematically
present but visually hidden because the head path was painted after the eye paths.

That is a **visual failure**, not an acceptable renderer result.

The implementation was corrected before certification.

---

## 11. Final visual paint order

The renderer now explicitly establishes paint order:

```text
head
 ↓
apertures
 ↓
lids
 ↓
creases/folds
 ↓
caruncle
 ↓
iris
 ↓
pupil
 ↓
reflection
```

The composition order is therefore no longer incorrectly treated as a rendering order.

The accepted board shows:

- front face;
- +12° placement rotation;
- -12° placement rotation;
- two visible eye apertures;
- iris/pupil assemblies;
- head contour and fill;
- consistent coordinate orientation.

## 12. Actual production render evidence

The QA tool invokes:

```text
build_human_face()
ProductionRenderSession.render_face()
```

and converts the exact returned SVG bytes to PNG.

No pixels are painted separately to simulate engine output.

Generated artifacts:

```text
V1.45_PRODUCTION_FACE_front.svg
V1.45_PRODUCTION_FACE_front.png
V1.45_PRODUCTION_FACE_tilt_plus.svg
V1.45_PRODUCTION_FACE_tilt_plus.png
V1.45_PRODUCTION_FACE_tilt_minus.svg
V1.45_PRODUCTION_FACE_tilt_minus.png
V1.45_PRODUCTION_VERTICAL_SLICE_RUNTIME_BOARD.png
```

The visual board was manually inspected after the paint-order correction.

The accepted visual scope is explicitly **head + two eyes**. Nose, mouth, ears and hair are
not rendered because no production geometry generators for those component kinds were added
in this brick.
