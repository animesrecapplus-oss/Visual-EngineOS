## 9. Database preparation

Migration `002_v0_9_visual_contracts.sql` adds:

- `component_visual_styles`
- `ocular_presentation_profiles`

The database remains a source of truth. Rendering must not query PostgreSQL in the geometry/pixel loop.

## 10. Deliberate nonclaims

Still not implemented:

- full 3D ocular anatomy;
- physical corneal refraction;
- true scene reflection projection;
- biological eyelid muscle simulation;
- automatic expression inference;
- general-purpose depth/occlusion solver;
- image-to-parameter reference extraction;
- full facial solver;
- true variable-width tapered SVG strokes;
- biological tear dynamics.

The architecture leaves explicit extension points for these systems rather than simulating them with arbitrary renderer conditionals.
