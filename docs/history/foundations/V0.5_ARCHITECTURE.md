# V0.5 — Eye Morphology, Gaze and Expressive Layers

## Purpose
V0.5 hardens the V0.4 eye vertical slice rather than replacing it. The eye remains a semantic component whose parameters produce deterministic geometry and SVG.

## Implemented layers

### Morphology
- `almond`, `round`, `large_round`, `narrow`, `droopy`, `sharp`, `upturned`, `downturned`
- sampled contour with configurable resolution
- upper/lower curvature controls
- rotation
- controlled wave/irregularity

### Iris
- circle/ellipse/hexagon/octagon geometry
- base/inner/outer colors
- rings
- radial/spoke pattern lines
- glow
- opacity

### Pupils
- one or many pupil specs
- ellipse/circle-like, vertical, horizontal and diamond forms
- independent position, scale, anisotropic scale, rotation, color and opacity
- gaze direction: center/up/down/left/right and four diagonals
- custom gaze vector remains supported
- pupil centers are conservatively clamped against the sampled eye contour with a radius margin

### Eyelashes
- optional
- density, count, length, thickness, curvature, color
- generated along the actual upper contour rather than a straight chord

### Eyebrows
- optional
- shape, length, thickness, density, angle, position and color

### State / marks
- closed/covered/wide-open behavior retained
- crying has a deterministic tear path/drop
- irritated/damaged states have explicit visible effects
- sclera spots can be supplied independently
- under-eye marks and stress intensity are supported

## Spatial placement foundation
`scene.eye_placement` adds a host-agnostic allocator for multiple eyes:
- deterministic candidate sampling
- frame margins
- minimum separation
- forbidden rectangular regions supplied by the host
- farthest-point distribution for frame coverage

This is intentionally **not** a face solver. A future face/host system will provide semantic forbidden regions such as nose and mouth zones. The same allocator can then be used for eyes on a forehead, arm, hand, creature body, etc.

## Important non-goals
V0.5 does not claim:
- physical 3D ocular anatomy or refraction
- true eyelid deformation around a gaze vector
- arbitrary external occluder geometry or partial occlusion solving
- full facial expression solving
- automatic understanding of an external anime reference
- production-quality raster anti-aliasing
- biologically accurate tear dynamics

## Determinism
SVG clip identifiers use a stable SHA-1 digest of geometry metadata instead of Python's process-randomized `hash()`. The same input/version therefore produces stable SVG identifiers across processes.
