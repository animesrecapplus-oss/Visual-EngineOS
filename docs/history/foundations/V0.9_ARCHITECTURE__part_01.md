# Visual Engine V0.9 — Eye system hardening

## Purpose

V0.9 does not replace the previous eye/pair architecture. It hardens it around concrete visual defects found in the V0.8 reference demos and turns the user's latest requirements into explicit contracts.

## 1. Eye pair is the default human unit

`EyePairSpec` is the normal entry point for a human face.

`human_default` means:

- same morphology definition by default;
- same structural parameters on both sides;
- controlled width/height/rotation asymmetry is permitted;
- appearance can differ independently;
- heterochromia changes iris appearance without changing morphology;
- `free` mode is reserved for non-human/fantasy/creature cases.

A pair is therefore not two unrelated `Eye` objects placed next to each other.

## 2. Eyelid geometry is now explicit

The old generic closed spline was replaced by two sampled curves:

- `upper_lid_points`
- `lower_lid_points`
- `inner_canthus`
- `outer_canthus`

The aperture is closed through a controlled canthus bridge. This prevents the previous lower-corner arrow/spike and prevents a self-intersecting clip path.

`contour_points` remains available for compatibility and solver work.

The pupil/iris/reflection layers are clipped by the actual eye aperture. They are never allowed to visually escape the aperture merely because a large gaze or explicit pupil offset was requested.

## 3. Contour is first-class visual data

`ContourSpec` defines:

- color;
- width;
- upper/lower width factors;
- opacity;
- cap;
- join;
- style.

The default contour is black. This is an eye-level implementation of the broader engine rule that visual components need explicit color and contour contracts.

Supported contour styles are represented in SVG rather than stored as labels only:

- `solid`
- `dashed`
- `double`
- `tapered` (reserved visual mode; current renderer keeps a stable solid fallback rather than falsely claiming true variable-width SVG geometry)

## 4. Eyelashes

Upper lashes are generated only from the upper eyelid curve.

The direction model is explicitly local to the eye:

- predominantly upward;
- regular spacing by default;
- controlled density;
- inner lashes can be shorter;
- outer-corner flare adds lateral direction while retaining an upward component;
- deterministic spacing jitter is optional;
- `natural`, `anime`, `spiky`, and `ornate` are actual renderer modes.

This replaces the previous contour-normal heuristic that could rotate lashes inward/downward around some eye shapes.

## 5. Eyebrow

Eyebrow remains a separate component.

It is constrained to the superior region of the eye at render time. Its style is data-driven:

- arched
- high_arch
- low_arch
- angular
- straight
- ornate
- long
- short
- thick
- faded

Additional controls include density, thickness, length, angle, ornament and end fading.

These are visual authoring parameters, not biological rules.

## 6. Presentation profiles

`OcularPresentationProfile` introduces explicit, optional visual profiles for:

- `young_child`
- `child`
- `adult`
- `elder`

and visual presentation:

- `neutral`
- `feminine_coded`
- `masculine_coded`

These presets do **not** infer gender/sex from an image and do not claim that all people in a category have a particular eye morphology. They are controlled style/morphology modifiers that can be overridden by the entity's own DNA.

The profile is applied to both eyes of a human pair by default, preserving bilateral identity.

## 7. Shot scale

The existing renderer-independent `ShotScale` vocabulary remains:

`DETAIL`, `CLOSE_UP`, `PORTRAIT`, `MEDIUM`, `WIDE`, `DISTANT`.

V0.9 does not falsely claim that shot scale is already a complete camera/framing solver. It is currently a semantic value object. Full camera projection and crop policy remain scene-system work.

## 8. Component color contract

The eye grammar now explicitly includes:

- Sclera
- Conjunctiva
- Cornea
- Iris
- Pupil
- LimbalRing
- UpperEyelid
- LowerEyelid
- InnerCanthus
- OuterCanthus
- Eyelashes
- Eyebrow
- TearSystem / TearFilm

The default visual contract is black contour with white sclera/conjunctiva and black pupil, while iris, hair-like components and accents have their own appearance definitions.
