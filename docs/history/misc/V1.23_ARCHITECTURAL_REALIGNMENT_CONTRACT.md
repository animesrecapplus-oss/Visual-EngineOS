# V1.23 — Architectural Realignment Contract

## Purpose

Restore the permanent ownership boundary crossed by the deep ocular/3D branch without deleting
that branch. The eye remains a Golden-Component stress test; generic runtime contracts remain domain-neutral.

## Ownership

```text
Generic LocalTransform
    x, y, rotation_deg, scale_x, scale_y, z

        ↓

Generic geometry_transform
    hierarchy composition
    scene placement
    camera affine transform
    z accumulation

        ↓

Eye-specific adapter
    ocular_yaw_deg
    ocular_pitch_deg
    alignment_axis_rotation_deg
    OcularBasis3D
```

## Invariants

1. `visual_engine.runtime.geometry_transform` must not import `visual_engine.components.face.eyes`.
2. `GeometryTransformResolution` must contain no ocular result fields.
3. `LocalTransform` must contain no ocular fields.
4. Generic component resolution must not execute ocular basis composition.
5. Eye-specific code may consume generic transforms without reimplementing hierarchy composition.
6. Legacy serialized ocular transform fields must migrate deterministically into component parameters.
7. Conflicting legacy and relational parameter values must fail closed.
8. Generic 2D matrices must remain unchanged by ocular parameters.
