# Visual Engine documentation index

## Navigation

- `governance/` — authoritative vision, architecture, roadmap, decisions, current status and mandatory engineering protocols.
- `components/eyes/` — eye component and micro-component contracts, blueprint and reference/calibration material.
- `runtime/` — generic placement, visibility, geometry, appearance and cache contracts.
- `domains/color/` — COLOR/appearance contracts and historical implementation records.
- `runtime/production/` — production vertical-slice contracts and reports V1.44–V1.47.
- `history/` — frozen historical architecture, audits and implementation logs.
- `governance/protocols/` — mandatory architectural immune-system and implementation gates.
- `refactor/` — documentation architecture, source modularization and cleanup records.

## Discipline

- Documentation files: **maximum 150 lines**, including generated navigation metadata.
- Generated validation evidence is disposable: `artifacts/` remains, but superseded generated contents are purged; only the current brick evidence under `artifacts/current/vX.Y/` remains at certification. The certified ZIP is the release boundary.
- Historical artifact paths may appear in frozen documents as historical references, but the generated files themselves are not retained.
- Historical documents are not silently rewritten to change their factual record.
- Missing historical records are documented as missing; they are never reconstructed by inference.
